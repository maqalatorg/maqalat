المهنيّ الذي يُتقن ChatGPT يوفّر 5-10 ساعات أسبوعياً. هذا الدليل يُظهر كيف، بأمثلة عملية.

## قبل البدء — سياسة الاستخدام الآمن

### 1) ChatGPT Team للمؤسّسة

- 25$/شهر/عضو
- بيانات **لا تُدرَّب** عليها
- مساحة عمل مشتركة
- ضمانات SOC 2

### 2) لا ترفع

- بيانات عملاء بأسمائهم
- عقود سرّية
- استراتيجيات تنافسية
- ملفّات موارد بشرية
- بيانات مالية غير منشورة

### 3) نعم ارفع

- بيانات مجهولة الهوية
- ملفّات عمل عامّة
- مستندات جاهزة للنشر
- بيانات لتحليل مبدئي (بلا معرّفات)

## استخدامات يومية — 15 عملي

### 1) مسوّغات الاجتماعات

**قبل**: 20 دقيقة تحضير

**بعد**: 3 دقائق

```
غداً اجتماع مع [العميل/الفريق] عن [الموضوع]. اقترح:
- 5 أسئلة أطرحها
- 3 نقاط أتحضّر لها
- احتمالات الاعتراضات وردودها.
```

### 2) محاضر اجتماعات

بعد الاجتماع، الصق ملاحظاتك السريعة، اطلب:

```
حوّلها إلى محضر رسمي بالبنية:
- التاريخ والحاضرون
- الأجندة
- ما نوقش لكل بند
- القرارات
- المهامّ (من، ماذا، متى).
```

### 3) عروض تقديمية

```
اكتب محتوى 10 شرائح لعرض عن [الموضوع]:
- الجمهور: [صف]
- المدّة: 20 دقيقة
- كل شريحة: عنوان + 3-5 نقاط + ملاحظة للمتحدّث.
```

### 4) تقارير أسبوعية

```
هذه إنجازات أسبوعي: [ألصق].
اكتب تقريراً أسبوعياً للإدارة، البنية:
- الإنجازات (5 نقاط)
- التحدّيات
- التخطيط الأسبوع القادم
- الحاجة لدعم.
```

### 5) تحليل ملفّ Excel

حمّل الملفّ، اطلب:

```
حلّل هذا الملفّ:
- ما القصّة العامّة؟
- 3 أنماط مهمّة
- 2 توصيات عملية
- رسم بياني أوضح النتائج.
```

Code Interpreter يشغّل بايثون ويعطيك تحليلاً بصرياً.

### 6) مسوّدات إيميلات صعبة

- إيميل رفض عرض
- إيميل اعتذار لعميل
- إيميل صعوبة توصيل خبر سيّئ
- إيميل تحفيز فريق

```
اكتب إيميل [الغرض] لـ[الشخص/الفريق].
الوضع: [صف].
الهدف: [محدّد].
اللهجة: [رسمية دافئة / حازمة محترمة / إلخ].
```

### 7) عصف ذهني

```
اقترح 20 فكرة لـ[التحدّي: زيادة مبيعات ربع، تحسين احتفاظ الموظّفين، إلخ].
- 10 عملية سريعة
- 10 استراتيجية طويلة.
```

### 8) تلخيص تقارير

حمّل تقرير 100 صفحة، اطلب:

```
لخّص هذا التقرير:
- أهمّ 10 نقاط
- الأرقام المالية الأساسية
- التوصيات الرئيسية
- ما يجب أن أنتبه إليه في اجتماع مع الإدارة.
```

### 9) ترجمة رسمية

بين العربية والإنجليزية، للاستخدام الداخلي (للرسمي: مترجم بشري).

### 10) رسائل شكر لعملاء

```
اكتب 30 رسالة شكر مخصّصة لعملاء [قائمة]، كل واحدة تذكر:
- اسم العميل
- خدمته/شراؤه الأخير
- ملاحظة شخصية.
```

### 11) تحليل مراجعات العملاء

الصق 100 مراجعة، اطلب:

```
- أهمّ 5 شكاوى (مرتّبة بالتكرار)
- أهمّ 5 نقاط إيجابية
- 3 اقتراحات تحسين
- ملاحظة عن الاتّجاه العام.
```

### 12) بيان صحفي

```
اكتب بيان صحفي لـ[الحدث/الإطلاق]:
- عنوان
- ملخّص (سطران)
- الجسم (3 فقرات)
- اقتباس تنفيذي
- خلفية الشركة
- بيانات الاتّصال.
```

### 13) توصيف وظيفي

```
اكتب توصيف وظيفة [الاسم] لـ[الشركة]:
- المسؤوليات
- المهارات المطلوبة
- المهارات المفضّلة
- ما نُقدّم
- كيفية التقديم.
```

### 14) خطّة تسويق ربع سنوية

```
اكتب خطّة تسويق ربع سنوية لـ[المنتج/الخدمة]:
- الأهداف
- الجمهور
- الرسائل
- القنوات
- الميزانية
- KPIs
- الجدول الزمني.
```

### 15) اقتراحات استثمار (استرشادي)

```
هذه بيانات مالية لمشروع محتمل: [ألصق].
حلّل من منظور استثماري:
- نقاط القوّة
- المخاطر
- 5 أسئلة يجب طرحها
- توصية استرشادية.
تذكير: للقرار النهائي، مستشار CMA-مرخّص.
```

## Custom GPTs للمهنيّ

بنِ 3-5 GPTs مخصّصة لمهامّك المتكرّرة:

### GPT #1: مساعد الإيميلات

تعليمات: "أنت مساعد كتابة إيميلات لـ[اسمك] في [شركتك]. صوت العلامة: [حدّد]. اكتب دائماً بالعربية. لا تستخدم كليشيهات."

### GPT #2: محلّل بيانات

تعليمات: "أنت محلّل بيانات. حين أرفع Excel/CSV، حلّل بأسلوب مؤسّسي: قصّة عامّة، 3 أنماط، توصيات، رسم بياني."

### GPT #3: مسوّغ اجتماع

تعليمات: "أعطيك سياق اجتماع، تعطيني: 5 أسئلة، 3 نقاط تحضير، احتمالات الاعتراضات."

### GPT #4: منشئ عروض

تعليمات: "أعطيك موضوعاً، تعطيني هيكل عرض 10 شرائح بأسلوب مؤسّسي."

### GPT #5: كاتب سوشيال ميديا

تعليمات: "أعطيك موضوعاً، تعطيني منشور LinkedIn (200 كلمة، هوك، قصّة، درس، سؤال)."

**النتيجة**: كل مهمّة متكرّرة تُنجَز في نصف الوقت.

## نصائح ذهبية

1. **اشتراك ChatGPT Team**، ليس شخصي — الأمان يستحقّ
2. **بنك Custom GPTs**، ليس برومتات من الصفر كل مرّة
3. **راجع كل مخرج قبل التسليم** — أنت المسؤول
4. **علّم فريقك** — 4 ساعات تدريب = 5x إنتاجية
5. **سياسة داخلية مكتوبة** — ماذا يُرفع، ماذا لا
