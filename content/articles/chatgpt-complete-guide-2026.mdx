ChatGPT هو المدخل الأشهر للذكاء الاصطناعي التوليدي. منذ إطلاقه في نوفمبر 2022، حصد أكثر من 500 مليون مستخدم أسبوعياً. هذا الدليل الشامل يفصّل كل ما يستطيع فعله في 2026.

## نظرة عامّة

**OpenAI** — الشركة الأمّ. تأسّست 2015، مدعومة بشدّة من Microsoft (13 مليار$ استثمار). Sam Altman مديرها التنفيذي.

**ChatGPT** — التطبيق الرئيسي، متاح ويب/موبايل/سطح مكتب.

**النماذج داخله**:

| النموذج | متى يُستخدم |
|---|---|
| **GPT-5** | الافتراضي الآن، الأشمل، يفكّر عند الحاجة |
| **GPT-5 mini** | أسرع، مجاني، للاستفسارات البسيطة |
| **o3** | تفكير طويل، للمسائل الصعبة (Pro) |
| **Sora 2** | توليد فيديو |
| **GPT-4o Voice** | Advanced Voice Mode |
| **DALL-E 3** | توليد صور (مدمج) |

## النسخ والتسعير

| النسخة | السعر | الأنسب لـ |
|---|---|---|
| **Free** | مجاناً | البدء، الاستخدام العادي |
| **Plus** | 20$/شهر | مستخدم يومي جادّ |
| **Team** | 25$/شهر/عضو | فرق صغيرة (2+) |
| **Enterprise** | مخصّص | شركات كبيرة |
| **Pro** | 200$/شهر | محترف يحتاج o3 غير محدود |

## الميزات الأساسية

### 1) المحادثة

الاستخدام الأساسي — اكتب، احصل على جواب. جرّب:
- كتابة مسوّدات (إيميلات، مقالات، تقارير)
- شرح مفاهيم بأساليب مختلفة
- ترجمة، تلخيص، إعادة صياغة
- عصف ذهني
- برمجة

### 2) توليد الصور (DALL-E 3 + GPT-4o Image)

اطلب صورة بالعربية أو الإنجليزية:
> "صمّم لي غلاف كتاب عن ريادة الأعمال، ألوان دافئة، أسلوب حديث، بلا نصّ عليه"

**النسخة المجانية**: 3 صور/يوم
**Plus**: بلا حدود عملية

### 3) Sora 2 — توليد الفيديو

للـPlus:
- 50 فيديو/شهر
- كل فيديو حتى 20 ثانية
- 720p (1080p للـPro)
- توصيل بمحادثة (تكتب سيناريو → Sora يصنعه)

### 4) Advanced Voice Mode

محادثة صوتية طبيعية (ليست TTS تقليدية):
- تفهم نبرتك
- تتوقّف حين تقاطعها
- تتفاعل بلهجات
- تستوعب لغات متعدّدة (منها العربية بجودة عالية)

**استخدامات**: محادثة تعلّم لغة، براين ستورمنغ، رفيق في المشي، مساعِد في السيارة.

### 5) Custom GPTs

بنِ مساعِداً مخصّصاً في دقائق:

**كيف**: My GPTs → Create → أدخل التعليمات + الملفّات.

**أمثلة شهيرة**:
- **Grimoire** — مساعد برمجة
- **Consensus** — بحث علمي بمصادر
- **Data Analyst** — تحليل بيانات

**بنِ خاصّاً بك**: مساعد كتابة بأسلوبك، مدرّس مادّتك، مستشار عملك.

**متجر GPTs** يفتح مصادر دخل — منشئون يحصلون على نسبة من الاستخدام.

### 6) Code Interpreter (Advanced Data Analysis)

يشغّل بايثون **مباشرة داخل المحادثة**:
- حلّ مسائل رياضية
- تحليل ملفّات Excel وCSV
- توليد رسوم بيانية
- معالجة صور
- تحويل بين تنسيقات ملفّات

### 7) Web Search

مفعّل افتراضياً — النموذج يبحث في الويب عند الحاجة، يستشهد بمصادر قابلة للنقر.

### 8) Deep Research

**Plus/Pro**: ChatGPT يذهب في مهمّة بحث موسّعة (5-30 دقيقة)، يقرأ عشرات المصادر، يكتب تقريراً كاملاً.

**متى**: قبل قرار كبير، تحضير تقرير معمّق، بحث معمّق قبل مقال.

### 9) Memory

يتذكّر تفضيلاتك عبر المحادثات:
- اسمك ومهنتك
- أسلوبك المفضّل
- مشاريعك الجارية

**تفعيل**: Settings → Personalization → Memory ON

### 10) Custom Instructions

تعليمات ثابتة تُطبَّق على كل محادثة:
- "What would you like ChatGPT to know about you?"
- "How would you like ChatGPT to respond?"

## الاستخدامات الاحترافية

### للكاتب

- مسوّدات مقالات (100 كلمة/دقيقة إنتاج)
- عناوين وأفكار
- تنقيح وتحرير
- تحويل مقال إلى ثريد سوشيال

### للمطوّر

- كود بويلر بلات
- تشخيص Bugs
- شرح كود قديم
- توليد اختبارات وحدة

### للمصمّم

- توليد صور تسويقية
- أفكار هوية بصرية (كبداية)
- شعارات مبدئية
- تحليل مواقع منافسين

### للمسوّق

- نسخ إعلانات بمئات النسخ للاختبار
- سكريبتات فيديو
- تحليل مراجعات العملاء
- كتابة إيميلات مخصّصة

### للطالب

- شرح مفاهيم بأساليب مختلفة
- توليد أسئلة تدريب
- ترجمة أوراق علمية
- تعلّم لغة تفاعلياً

## نصائح للاستخدام الأمثل

1. **جرّب Custom GPTs** — يوفّر تكرار التعليمات
2. **فعّل Memory** — يخصّص لك المخرج
3. **استخدم Code Interpreter** لأيّ تحليل بيانات
4. **جرّب Voice** لمهام صعبة أثناء المشي
5. **Deep Research قبل القرار الكبير**
6. **راجع كل مصدر** يذكره — النموذج قد يخترع

## المخاطر والقيود

- **الهلوسة**: يخترع مصادر، أرقام، سوابق
- **الخصوصية**: لا ترفع بيانات حسّاسة بحساب مجاني
- **التقلّبات**: نفس السؤال قد يعطي جوابَين مختلفَين
- **العربية أقلّ دقّة** من الإنجليزية في بعض المهام
- **التحيّزات** ثقافية وسياسية في بيانات التدريب
