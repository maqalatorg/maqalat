**تحذير**: كل ما يلي **White-Hat SEO** فقط، احترام قواعد Google. لا Black-Hat (Cloaking، keyword stuffing، PBN).

## لبحث الكلمات المفتاحية (5)

### 1) توليد كلمات مفتاحية

```
اقترح 30 كلمة مفتاحية لموقع عن [الموضوع].
مقسّمة:
- 10 head keywords (حجم بحث عالٍ)
- 15 long-tail (تحويل عالٍ، منافسة أقلّ)
- 5 questions (Featured Snippet)
اذكر: قصد البحث المتوقّع لكل كلمة.
```

### 2) عناقيد المحتوى (Topic Clusters)

```
صمّم topic cluster حول الكلمة الأمّ: [الكلمة].
- Pillar page: [الاسم المقترَح، 3000+ كلمة]
- 8-12 supporting pages بعناوين محدّدة
- كيف تُربط داخلياً (Internal Linking Strategy).
```

### 3) تحليل قصد البحث

```
حلّل قصد البحث لهذه الكلمات: [قائمة].
كل كلمة:
- Informational / Navigational / Commercial / Transactional
- نوع المحتوى المناسب
- Angle الأنسب.
```

### 4) كلمات المنافس

```
هذه أهمّ كلمات لمنافسي: [ألصق قائمة].
- أيّها يمكن أن أستهدفه بواقعية؟
- أيّها فرص مفقودة (Content Gap)؟
- كيف أفوز على المنافس فيها؟
```

### 5) Semantic Keywords

```
لصفحة تستهدف الكلمة [X]، اقترح:
- 20 semantic keyword (LSI) مرتبطة
- 15 مصطلح متخصّص أذكره
- 10 سؤالاً يطرحه القارئ.
```

## للمحتوى (5)

### 6) هيكل مقال SEO

```
اكتب هيكل مقال 2000 كلمة لاستهداف الكلمة [X].
البنية:
- H1 (يحوي الكلمة)
- Introduction (100 كلمة، الكلمة في أوّل 50)
- 5-7 H2 (كل واحد يحوي كلمة LSI)
- 2-3 H3 لكل H2
- FAQ (5 أسئلة، Schema-ready)
- CTA.
```

### 7) Meta Title & Description

```
اكتب 5 نسخ meta title (55-60 حرف) و meta description (150-160 حرف) لصفحة عن [الموضوع].
- الكلمة المفتاحية في أوّل 30 حرف من العنوان
- كل نسخة بزاوية مختلفة
- الوصف يحتوي CTA طبيعي.
```

### 8) Featured Snippet

```
اكتب فقرة 40-60 كلمة تجيب مباشرة على السؤال [X] بأسلوب يستهدف Featured Snippet.
- إجابة أولى مباشرة
- تفاصيل داعمة
- بلا تكرار السؤال.
```

### 9) FAQ Schema

```
اكتب 8 أسئلة وأجوبة لصفحة [الموضوع] بأسلوب FAQPage Schema.
- كل سؤال يستهدف long-tail keyword
- الجواب 40-80 كلمة
- مباشر ومفيد.
```

### 10) محتوى تحسين (Content Refresh)

```
هذا مقال قديم أُريد تحديثه: [ألصق].
- ما التحديثات المطلوبة؟
- إحصاءات جديدة
- مصطلحات معاصرة
- أقسام مفقودة
- تحسين البنية.
```

## للتقني (5)

### 11) Schema Markup

```
اكتب Schema.org JSON-LD لصفحة [نوع: Article / Product / LocalBusiness / Recipe / FAQ / HowTo].
- كل الحقول الإلزامية
- الحقول الاختيارية المهمّة
- Valid JSON.
```

### 12) Alt Text للصور

```
اكتب alt text لهذه الصور: [قائمة أسماء/أوصاف].
- وصفي دقيق (5-15 كلمة)
- يحوي الكلمة المفتاحية طبيعياً
- ليس keyword stuffing.
```

### 13) URL Slug

```
اقترح URL slug لصفحة عنوانها: [العنوان].
- إنجليزي، قصير (تحت 60 حرف)
- يحوي الكلمة المفتاحية
- بلا كلمات وقفية (a, the, of)
- Hyphens بين الكلمات.
```

### 14) Internal Linking

```
هذا مقالي: [ألصق].
هذه صفحات موقعي: [قائمة].
اقترح 5-8 روابط داخلية طبيعية داخل المقال.
- النصّ المرابط (anchor text) بلا "اضغط هنا"
- تناسب سياقياً.
```

### 15) Redirect Plan

```
سأنقل صفحات من موقعي القديم للجديد. الصفحات: [قائمة].
اكتب:
- 301 redirects لكل صفحة
- أولوية النقل
- ما نفعل بالصفحات بلا مقابل.
```

## للتحليل والاستراتيجية (5)

### 16) تحليل SERP

```
هذه أوّل 10 نتائج على Google لكلمة [X]: [ألصق العناوين].
- ما الأنماط المشتركة؟
- أنواع المحتوى (بلوق، منتج، فيديو)؟
- كيف أفوز بمحتوى أفضل؟
- Angle مختلف.
```

### 17) تدقيق SEO لصفحة

```
دقّق SEO لهذه الصفحة: [ألصق HTML أو ملخّص].
- Title, Meta, Headers
- الكلمات المفتاحية (density، وضع)
- Alt text
- Internal links
- Load time hints
- Mobile-friendliness.
اذكر: ما يحتاج إصلاحاً فوراً.
```

### 18) استراتيجية Content Calendar

```
صمّم content calendar SEO 3 أشهر لموقع في مجال [X].
- 4 مقالات أسبوعياً
- مزيج من: pillar (2/شهر)، supporting (10/شهر)، news (بحسب المستجدّات)
- كل مقال: الكلمة المستهدَفة، قصد البحث، عدد كلمات مستهدَف.
```

### 19) Link Building Outreach

```
اكتب إيميل outreach لطلب backlink من موقع [X] لمقالي [Y].
- شخصي (اذكر شيئاً محدّداً من موقعهم)
- قيمة مقدَّمة لهم (guest post مجاني، إحصاء، أداة)
- طلب واضح
- قصير (150 كلمة).
```

### 20) تقرير أداء

```
هذه بيانات Google Search Console لموقعي: [ألصق].
- أفضل صفحات الأداء
- أضعف صفحات
- كلمات مفقودة الفرصة (impressions عالية، CTR منخفض)
- 5 توصيات لتحسين الأداء.
```

## قواعد White-Hat مهمّة

1. **لا keyword stuffing**، الكلمة تظهر طبيعياً
2. **محتوى بشري المراجعة**، لا publish خام من AI
3. **مصادر رسمية**، E-E-A-T
4. **لا PBN أو backlinks مدفوعة**، عقوبة Google
5. **لا Cloaking**، لا محتوى مختلف للبوتس والمستخدمين

## أدوات مكمّلة

- **SEMrush**، أبحاث شاملة
- **Ahrefs**، backlinks + كلمات
- **Google Search Console** (مجاني)، بيانات موقعك الحقيقية
- **Screaming Frog**، تدقيق تقني
- **Surfer SEO**، تحسين محتوى
