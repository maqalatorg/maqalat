**تحذير YMYL**: البرومتات التالية للتحليل والتعلّم. القرارات الاستثمارية الفعلية تحتاج مستشاراً مرخّصاً من [هيئة السوق المالية (CMA)](https://cma.org.sa).

## للتحليل الأساسي (5 برومتات)

### 1) تحليل شركة

```
حلّل الشركة [الاسم] من منظور استثماري.
البنية:
- نبذة (منتج، سوق، حجم)
- الأرقام الأخيرة (إيرادات، أرباح، هوامش)
- المنافسون الرئيسيون
- نقاط قوّة
- مخاطر
- الرأي: ملخّص + تحفّظ (احتمال الخطأ في البيانات).
اذكر مصادرك (ولو تحتاج تحقّق بشرياً).
```

### 2) قراءة قوائم مالية

```
هذه قائمة الدخل / الميزانية / التدفقات النقدية لشركة [X]: [ألصق].
اشرح لي كـ [مبتدئ / محترف]:
- ما تقوله الأرقام؟
- ما المؤشّرات الجيّدة؟
- ما المؤشّرات المقلقة؟
- 3 أسئلة يجب أن أطرحها.
```

### 3) نسب مالية

```
احسب النسب المالية الرئيسية لشركة [X] من بياناتها: [ألصق].
- P/E, P/B, ROE, ROA, Debt-to-Equity, Current Ratio, Quick Ratio.
- قارنها بمعدّل الصناعة.
- اذكر ما تعنيه كل نسبة.
```

### 4) تحليل SWOT مالي

```
تحليل SWOT من منظور مالي لشركة [X]:
- Strengths (المالية)
- Weaknesses (المالية)
- Opportunities (السوق)
- Threats (المنافسة/الاقتصاد).
5 نقاط لكل قسم.
```

### 5) مقارنة شركتَين

```
قارن بين شركتَين [A] و[B] كمرشّحتَين للاستثمار.
البنية: جدول 10 معايير (نمو، هوامش، ديون، دفعات أرباح، إلخ)، ملخّص لكل شركة، ملاحظات، ملخّص القرار.
```

## للمحفظة (5 برومتات)

### 6) تقييم محفظتي

```
هذه محفظتي: [ألصق قائمة الأسهم/الصناديق ونسبها].
- Asset allocation صحيح؟
- تنوّع كافٍ؟
- تركّز عالٍ في قطاع أو سهم؟
- ما تعديلات مقترَحة؟
تذكير: نصائح تعليمية، القرار مع مستشار.
```

### 7) توزيع أصول

```
اقترح توزيع أصول (Asset Allocation) لشخص:
- عمر [X]
- دخل [Y]
- أهداف [متقاعد في 20 سنة / شراء منزل في 5 / إلخ]
- تحمّل مخاطر [منخفض / متوسّط / عالٍ]
- إلتزامات: [عائلة / لا].
- قيود: [حلال فقط / نعم / لا].
```

### 8) Rebalance محفظة

```
محفظتي الأصلية: [نسب].
محفظتي الآن (بعد تحرّكات السوق): [نسب].
احسب:
- كم أشتري/أبيع لإعادة التوازن.
- التكلفة التقديرية.
- الضريبة المحتملة.
```

### 9) استراتيجية DCA

```
أريد استثمار [X] ريال شهرياً في [صندوق/سهم].
- كم سنة سيصل رأس مالي إلى [Y]؟ (بافتراض عائد [Z%]).
- ما مخاطر هذه الاستراتيجية؟
- كيف أتعامل مع فترات هبوط السوق؟
```

### 10) خطّة تقاعد مبسّطة

```
أريد التقاعد في عمر [X] بدخل شهري [Y] ريال.
عمري الآن [Z]، مدّخراتي [A].
- كم أحتاج ادّخاره شهرياً؟
- افتراضات (عائد، تضخّم).
- 3 سيناريوهات: متفائل، متحفّظ، محافظ.
تذكير: أرقام تقديرية للتخطيط الأوّلي.
```

## للميزانية الشخصية (5 برومتات)

### 11) تحليل مصاريفي

```
مصاريفي الشهرية: [ألصق تفصيلاً].
- ما نسبة كل فئة؟
- ما الفئات المرتفعة مقارنة بالمعتاد؟
- ٥ اقتراحات للتقليل.
```

### 12) ميزانية 50-30-20

```
دخلي الشهري [X].
اقسم لي ميزانية 50-30-20:
- 50% احتياجات (تفصيل: إيجار، طعام، مواصلات)
- 30% رغبات
- 20% ادّخار/استثمار.
```

### 13) خطّة سداد ديون

```
لديّ ديون: [ألصق قائمة: مبلغ، فائدة، حدّ أدنى].
دخلي [X]، أستطيع تخصيص [Y] شهرياً للسداد.
- ما استراتيجية السداد الأمثل (Avalanche / Snowball)؟
- خطّة شهرية.
- المدّة المتوقّعة.
```

### 14) صندوق طوارئ

```
عمري [X]، دخلي [Y]، مصاريفي [Z].
- كم يجب أن يكون صندوق طوارئي (3 / 6 / 12 شهراً)؟
- كم شهراً أحتاج لبنائه بادّخار [W] شهرياً؟
- أين أضعه (حساب توفير / صندوق سيولة)؟
```

### 15) شراء منزل vs إيجار

```
أفكّر في شراء منزل بـ[X] ريال، دفعة أولى [Y]، تمويل [Z] سنوات بربح [R%].
الإيجار المقابل: [W] ريال.
حلّل: أيّهما أفضل مالياً على 5، 10، 20 سنة؟
عوامل تجاهلها: [تفضيل شخصي، استقرار عائلي].
```

## للاستثمار والقرارات (5 برومتات)

### 16) تحليل عرض استثماري

```
هذا عرض استثماري: [ألصق].
- ما نموذج العمل؟
- ما الأرقام المفترضة؟
- ما الافتراضات المشكوكة؟
- 5 أسئلة أطرحها قبل الاستثمار.
- Red flags.
تذكير: هذا تحليل استرشادي.
```

### 17) تقييم Startup

```
أفكّر في الاستثمار في Startup: [ألصق ملخّص].
- Team quality
- Market size
- Product-market fit
- Competitive moat
- Traction
- Terms of investment.
اكتب ملاحظات ونقاط ضعف.
```

### 18) قرار مالي شخصي

```
لديّ [X] ريال إضافي هذا الشهر. الخيارات:
1. تسديد قرض (فائدة X%، مدّة Y)
2. استثمار في [صندوق] (عائد متوقّع Z%)
3. صندوق طوارئ
4. ترفيه شخصي
ما الأولوية من منظور مالي؟ لماذا؟
```

### 19) توقّع تضخّم

```
احسب: كم سيكون [X] ريال بعد 10 سنوات بتضخّم متوسّط [Y%]؟
- القوّة الشرائية الحالية vs المستقبلية
- ماذا يعني هذا للتقاعد؟
- كيف يحمي الاستثمار من التضخّم؟
```

### 20) تخطيط الزكاة

```
لديّ:
- أموال نقدية: [X]
- استثمارات: [Y]
- ذهب: [Z]
احسب الزكاة على كل صنف حسب الفقه الإسلامي.
اذكر: النصاب، متى يحلّ الحول، ما لا تجب فيه الزكاة.
```

## نصائح ذهبية

1. **راجع كل رقم**، النموذج قد يخترع أو يستخدم بيانات قديمة
2. **لا تعتمد على AI في القرار النهائي**، استشر CMA-مرخّص
3. **افهم ثمّ نفّذ**، لا تنفّذ ما لا تفهم
4. **البيانات الشخصية**، لا ترفعها على حسابات مجانية غير آمنة
5. **الأنظمة السعودية**، تحقّق من ZATCA، SAMA، CMA للأرقام الرسمية
