بدل قضاء ساعات في صياغة برومت مثالي، **اطلب من النموذج يكتبه لك**. الفكرة بسيطة، النتائج مذهلة. هذا الدليل يشرح Meta-Prompting بأمثلة عملية.

## الفكرة الأساسية

النماذج مدرّبة على مليارات النصوص، منها أدلّة البرومت الأفضل. تعرف قواعد Chain of Thought، Role Prompting، Few-Shot، ونماذج البرومت الناجحة. لماذا لا نستفيد؟

**بدل**:
> "اكتب لي برومت جيد لتلخيص المقالات"

**اطلب**:
> "أريد برومتاً يعطيني أفضل تلخيص للمقالات. اكتب لي البرومت الأمثل، مع شرح لماذا اخترت كل جزء."

النموذج يكتب لك برومتاً بجزئيه (System + User)، مع تفكيره.

## البرومت الأساسي لـMeta-Prompting

```
أريد أن أستخدمك في مهمّة: [صف المهمّة بجملة].

الجمهور المستفيد من المخرج: [صف].
الشكل المطلوب للمخرج: [جدول/فقرة/JSON/إلخ].
القيود الأساسية: [ما تريده أو لا تريده].

اكتب لي البرومت الأمثل الذي يجعلك تعطي أفضل مخرج ممكن.
اشرح لماذا كل جزء من البرومت.
```

## أمثلة عملية

### مثال 1: توليد برومت لكاتب سوشيال ميديا

**الطلب**:
```
أريدك تكتب لي منشورات LinkedIn تنمّي حسابي كمسوّق رقمي سعودي.
جمهوري: أصحاب مشاريع صغيرة، 25-45 سنة.
هدفي: بناء ثقة، جذب استشارات.
شكل المخرج: منشور 150-200 كلمة.

اكتب لي البرومت الأمثل الذي أستخدمه معك كل مرّة.
```

**مخرج النموذج**:
> **البرومت المقترح**:
> 
> "أنت [اسم المستخدم]، مسوّق رقمي سعودي بخبرة X سنوات. جمهورك على LinkedIn: أصحاب مشاريع صغيرة (25-45 سنة، السعودية والخليج). صوتك: خبير عملي، بلا مصطلحات معقّدة، أمثلة سعودية، رأي بقناعة.
> 
> اكتب منشور LinkedIn 150-200 كلمة عن الموضوع الذي سأعطيك.
> 
> البنية:
> - افتتاحية بجملة تصدم أو تحيّر (لا 'في هذا العالم')
> - قصّة/مثال شخصي محدّد (تفاصيل حقيقية)
> - درس واحد فقط
> - سؤال يدعو للتعليق
> 
> لا تستخدم: كليشيهات، إيموجي أكثر من 2، هاشتاق أكثر من 3."
> 
> **لماذا كل جزء**:
> - "أنت [الاسم]"، يُبني هوية شخصية
> - "خبرة X سنة"، يستدعي عمقاً
> - "صوتك: خبير عملي"، يُحدّد النبرة
> - "البنية"، يضمن اتّساقاً
> - "لا تستخدم"، يمنع أنماط AI الشائعة

**النتيجة**: برومت جاهز، أفضل ممّا كنت ستكتبه بنفسك.

### مثال 2: توليد برومت للتحليل المالي

```
سأعطيك أرقام مبيعات شهرية لمتجري، وأريد تحليلاً يساعدني اتخذ قرارات.
لا أفهم كثيراً في الإحصاء.
أريد المخرج: نقاط عملية، جدول، توصية واحدة أهمّ.

اكتب البرومت الأمثل.
```

النموذج يكتب برومتاً يحدّد: الدور (محلّل بيانات مبسّط)، البنية (نقاط + جدول + توصية)، القيود (لغة غير تقنية).

## Anthropic Prompt Generator

**Anthropic** أطلقت أداة رسمية: **Prompt Generator** في [console.anthropic.com](https://console.anthropic.com/) (تحتاج حساباً).

**كيف تعمل**:
1. تكتب مهمّتك بجملة
2. تختار متغيّرات المدخل
3. تضغط "Generate"
4. تحصل على System Prompt + User Prompt Template

**مثال**:
- المهمّة: "استخرج معلومات المريض من ملاحظات الطبيب"
- المتغيّر: `{{DOCTOR_NOTES}}`

الأداة تكتب:
> **System**: "You are a medical data extraction assistant..."
> **User Template**: "Extract structured patient information from: {{DOCTOR_NOTES}}..."

جاهز للاستخدام.

## Meta-Prompting المتقدّم

### 1) توليد Few-Shot Examples

```
أريد تصنيف مراجعات المطاعم إلى [ممتاز / جيّد / متوسّط / سيّئ].
اكتب لي 5 أمثلة (مراجعة + التصنيف الصحيح) تعلّم النموذج بدقّة.
```

النموذج يولّد أمثلة متنوّعة تُغطّي حالات مختلفة.

### 2) توليد Constraints

```
أريدك تكتب مقالات مدوّنة عن المنتج X.
اكتب لي قائمة القيود ('لا تفعل') التي تضمن أعلى جودة.
```

يعطيك قائمة "ممنوعات" (مصطلحات مضلّلة، ادّعاءات، أنماط AI شائعة).

### 3) توليد Testing Rubric

```
كتبت هذا البرومت: [الصق].
اكتب لي 10 أسئلة اختبار (Test Cases) تُقيّم جودة مخرجاته.
كل اختبار مع توقّع الجواب المثالي.
```

## Meta-Prompting للأتمتة

للمطوّرين الذين يبنون تطبيقات AI: Meta-Prompting نفسه يمكن أتمتته.

**السيناريو**: تطبيق يستقبل مهام متنوّعة من المستخدمين.

**الحلّ**: 
1. المستخدم يصف مهمّته
2. النموذج يولّد Prompt مخصّص للمهمّة
3. Prompt المُولَّد يُستخدم مع نموذج ثانٍ لتنفيذ المهمّة
4. النتيجة تعود للمستخدم

**نموذج شهير يستخدم هذا**: DSPy من Stanford (framework للـProgrammatic Prompting).

## متى Meta-Prompting قد لا يعمل

### 1) المهام البسيطة جدّاً

"لخّص هذا"، لا تحتاج meta.

### 2) المهام الحسّاسة قانونياً

Meta قد يقترح برومتاً يعطي مخرجاً قانونياً محرَجاً. راجع دائماً.

### 3) في نموذج ضعيف

Meta-Prompting يعتمد على قوّة النموذج. GPT-4 mini قد يولّد برومتاً متوسّطاً. GPT-5 يولّد ممتازاً.

## قوالب Meta-Prompting جاهزة

### قالب "حسّن برومتي"

```
هذا هو برومتي الحالي: 
[الصق]

مخرجاته أحياناً: 
[صف المشكلة]

حلّل البرومت، اقترح تحسينات، ثم أعد كتابته محسّناً.
اشرح كل تعديل.
```

### قالب "برومت من الصفر"

```
أريد استخدامك في مهمّة: [الوصف بجملة].
جمهور المخرج: [من؟].
شكل المخرج: [كيف؟].
أنماط أرفضها: [ما تكرهه].
مثال على مخرج ممتاز: [إن وُجد].

اكتب لي System Prompt + User Prompt Template.
اشرح كل جزء.
```

### قالب "برومت لأتمتة"

```
أبني أداة تستخدمك عبر API لمهمّة: [الوصف].
المستخدم يُدخل: [المتغيّرات].
الأداة تُظهر: [المخرج المتوقّع].

اكتب لي:
1. System Prompt الأمثل
2. User Prompt Template بمتغيّرات {{X}}
3. 3 اختبارات لضمان الجودة
```

## نصائح ذهبية

1. **جرّب Meta على أهمّ 3 مهام** تُكرّرها، وفّر ساعات
2. **احتفظ ببنك Prompts** المولّدة، ابنِ عليها
3. **راجع بشرياً** ما يولّده النموذج، قد يفوت نكتة
4. **اختبر عمليّاً**، البرومت الجميل نظرياً قد يفشل عملياً
5. **جدّد كل 6 أشهر**، النماذج تتطوّر، أفضل Prompts تتغيّر
