المسوّق الذكي في 2026 يستخدم AI ليكبّر إنتاجه 5x. هذه 30 برومت اختُبرت في حملات حقيقية.

## للإعلانات (10 برومتات)

### 1) إعلان Meta (Facebook/Instagram)

```
اكتب 5 نسخ إعلان Meta لمنتج/خدمة: [صف].
الجمهور: [العمر، الجنس، الاهتمامات، الموقع].
الهدف: [conversions / awareness / leads].
البنية: هوك (سطر 1)، فائدة (سطران)، CTA.
تجنّب: كلمات ممنوعة (100%، مضمون، عاجل).
```

### 2) إعلان Google Search

```
اكتب Google Search Ads لكلمة مفتاحية: [الكلمة].
- 15 عنواناً (كل تحت 30 حرف)
- 4 أوصاف (كل تحت 90 حرف)
- سطران للـURL Path
- Sitelink Extensions (4 قوالب).
اجعلها متنوّعة في الزاوية.
```

### 3) إعلان TikTok

```
اكتب سكريبت إعلان TikTok 15 ثانية لـ[المنتج].
البنية: هوك (3 ثوانٍ صادم)، مشكلة، حلّ (منتجك)، CTA.
لغة محكية، سرعة عالية.
```

### 4) إعلان LinkedIn Ad

```
اكتب إعلان LinkedIn Sponsored Content لـ[الخدمة B2B].
الجمهور: [مدراء تنفيذيون في قطاع X].
البنية: بيان صادم أو إحصاء، فائدة رئيسية، Social proof (أرقام أو عميل)، CTA.
```

### 5) إعلان Snapchat

```
اكتب إعلان Snapchat 5-10 ثوانٍ لـ[المنتج].
الجمهور: 18-25 سنة، السعودية.
هوك بصري بسيط، رسالة واحدة، CTA بسيط.
```

### 6) عنوان إعلان مغري

```
اكتب 20 عنواناً جذّاباً لإعلان عن [المنتج].
مقسّمة إلى:
- 5 عناوين خوف (FOMO)
- 5 عناوين فضول
- 5 عناوين فائدة مباشرة
- 5 عناوين اجتماعية (Social Proof).
```

### 7) وصف بيني (Description) لإعلان

```
اكتب 10 أوصاف قصيرة (90 حرف) لإعلان [المنتج].
كل واحد يشدّد على فائدة مختلفة.
تجنّب الأفعال الأمريكية "Buy Now" — استخدم دعوات سعودية طبيعية.
```

### 8) CTA (Call-to-Action)

```
اكتب 15 CTA مختلف لصفحة هبوط تبيع [المنتج].
مقسّمة:
- 5 مباشرة (اطلب الآن، اشترِ)
- 5 قيمة (خذ التجربة، احصل على الدليل)
- 5 استكشاف (اعرف كيف، شاهد كيف).
```

### 9) Retargeting Ad

```
اكتب إعلان retargeting لعملاء زاروا صفحة [المنتج] ولم يشتروا.
اللهجة: تذكيرية غير ضاغطة، مع محفّز (تخفيض / شهادة / ضمان).
2 عناوين + وصف.
```

### 10) A/B Test إعلانَين

```
اكتب نسختَين من إعلان [المنتج]:
- النسخة أ: عاطفية (تركّز على الشعور)
- النسخة ب: منطقية (تركّز على الحقائق)
كلاهما لنفس المنتج والجمهور.
```

## للمحتوى (10 برومتات)

### 11) محتوى بلوق SEO

```
اكتب مقال بلوق 1500 كلمة عن [الكلمة المفتاحية].
- Search intent: [informational / transactional]
- الكلمة في: العنوان، أوّل 100 كلمة، H2s، meta description
- 5 H2 sections
- FAQ 5 أسئلة (Schema)
- 3 links داخلية، 2 خارجية.
```

### 12) عصف ذهني لأفكار محتوى

```
عصف ذهني: 30 فكرة محتوى لصفحتي على [المنصّة] في مجال [X].
مقسّمة إلى:
- 10 تعليمية (كيف تفعل)
- 10 مثيرة للتفاعل (سؤال، رأي)
- 10 خلف الكواليس (شخصية).
```

### 13) Content Calendar شهري

```
صمّم content calendar لشهر لـ[العلامة].
- منصّة: [LinkedIn / Instagram / TikTok / متعدّد]
- تكرار النشر: [4 مرّات أسبوعياً]
- المزيج: 40% تعليمي، 30% تفاعلي، 20% ترويجي، 10% ترفيهي.
- كل منشور: يوم، وقت، موضوع، شكل.
```

### 14) نصّ فيديو يوتيوب

```
اكتب سكريبت فيديو يوتيوب 8 دقائق عن [الموضوع].
البنية: هوك (30 ثانية)، مقدّمة (30 ثانية)، محتوى (6 دقائق مقسّمة إلى 5 نقاط)، خاتمة + CTA (60 ثانية).
لغة محكية طبيعية.
```

### 15) Blog Series (5 مقالات مترابطة)

```
صمّم سلسلة 5 مقالات مترابطة عن [الموضوع الأمّ].
كل مقال بعنوان، فكرة رئيسية، 3 عناوين فرعية.
السلسلة تُبنى تدرّجياً من مبتدئ إلى متقدّم.
```

### 16) Case Study تسويقي

```
اكتب دراسة حالة تسويقية عن حملة نجحت (اختراعية للتدريب): 
- العميل: [صف]
- التحدّي: [صف]
- الاستراتيجية: [صف]
- النتائج (بأرقام): [صف]
- الدروس.
```

### 17) Whitepaper

```
اكتب Whitepaper 2000 كلمة عن [الموضوع].
الجمهور: صنّاع قرار في [الصناعة].
البنية: ملخّص تنفيذي، مشكلة، تحليل السوق، حلّنا، دراسات حالة، خلاصة + CTA.
مصادر رسمية.
```

### 18) نيوزلتر أسبوعي

```
اكتب نيوزلتر أسبوعي 400 كلمة لجمهور [صف].
البنية: افتتاحية شخصية، أهمّ 3 أخبار في المجال، أداة/مقال أنصح به، سؤال للأسبوع.
لهجة ودّية شخصية.
```

### 19) بريد ترحيبي (Welcome Series)

```
اكتب 5 إيميلات ترحيبية لمشترك جديد في نيوزلتر [الموضوع].
كل إيميل بغرض: تعارف، قيمة أولى، قصّة، منتج/خدمة، دعوة تفاعل.
مساحات زمنية: يوم 0، 2، 5، 8، 14.
```

### 20) بيان صحفي

```
اكتب بيان صحفي لـ[الحدث/الإطلاق].
البنية: عنوان، ملخّص (سطران)، فقرة رئيسية، اقتباس تنفيذي، خلفية، الشركة، تواصل.
لهجة رسمية.
```

## للاستراتيجية والبحث (10 برومتات)

### 21) ICP (Ideal Customer Profile)

```
حدّد ICP لمنتج [صف].
- الديموغرافيا (عمر، جنس، دخل، موقع)
- Psychographics (قيم، اهتمامات، مخاوف)
- سلوك شراء (متى، أين، كيف)
- نقاط الألم
- بدائل يستخدمها الآن.
```

### 22) Buyer Persona

```
اكتب 3 buyer personas لـ[المنتج].
كل persona:
- اسم مختصر (مثلاً: أحمد المطوّر، سارة المديرة)
- خلفية شخصية 3 أسطر
- أهداف
- تحدّيات
- كيف يبحث عن حلول
- ما يمنعه من الشراء
- CTA الأنسب.
```

### 23) SWOT للتسويق

```
حلّل SWOT للاستراتيجية التسويقية لـ[العلامة]:
- Strengths (5)
- Weaknesses (5)
- Opportunities (5)
- Threats (5)
اذكر أهمّ فرصة يجب اقتناصها.
```

### 24) تحليل منافسين

```
حلّل 3 منافسين لـ[العلامة]: [أسماء].
لكل منافس:
- منتجه/خدمته
- تسعيره
- استراتيجية تسويقه (SEO، إعلانات، محتوى)
- نقاط قوّة
- نقاط ضعف نستغلّها.
```

### 25) استراتيجية دخول سوق

```
صمّم استراتيجية دخول [المنتج/الخدمة] إلى السوق [السعودي/الخليجي].
- تحليل السوق
- الجمهور المستهدف
- تسعير
- قنوات التوزيع
- خطّة تسويق 90 يوم
- KPIs.
```

### 26) Growth Hacks

```
اقترح 10 growth hacks لـ[المنتج/الخدمة].
كل hack:
- الفكرة بجملة
- التنفيذ
- المخاطرة
- التكلفة التقديرية
- KPI للنجاح.
```

### 27) Funnel Analysis

```
حلّل funnel التحويل لـ[المنتج]:
- عدد الزوّار [X]
- عدد الاشتراكات [Y]
- عدد المشترين [Z]
- LTV [$]
اذكر: أضعف نقطة، أفضل 3 تحسينات، توقّع التأثير.
```

### 28) Positioning Statement

```
اكتب positioning statement لـ[العلامة].
الصيغة: لـ[الجمهور] الذي [الحاجة]، [العلامة] هي [الفئة] التي [الفائدة الفريدة]، على عكس [المنافسين] الذين [نقطة الضعف].
```

### 29) بحث كلمات مفتاحية

```
اقترح 30 كلمة مفتاحية لـ[الموضوع/المنتج].
مقسّمة:
- 10 head keywords (حجم بحث عالٍ)
- 15 long-tail (تحويل عالٍ)
- 5 questions (تستهدف Featured Snippets)
مع تقدير Intent لكل واحدة.
```

### 30) تقرير حملة

```
اكتب تقرير أداء حملة تسويقية:
- الحملة: [الاسم، المدّة، الميزانية]
- KPIs: [أرقام قبل وبعد]
- ما نجح
- ما لم ينجح
- توصيات للحملة القادمة.
```

## أدوات مكمّلة للمسوّق

- **Canva**، تصميم سوشيال
- **Buffer/Hootsuite**، جدولة
- **Zapier**، أتمتة سير العمل
- **SEMrush/Ahrefs**، SEO
- **HubSpot**، CRM + Marketing
- **Perplexity**، بحث سوق

## نصائح ذهبية

1. **AI مساعد، لست بديل**، القرار الاستراتيجي لك
2. **اختبر A/B دائماً**، لا تصدّق مخرج AI بلا بيانات
3. **راجع الأرقام**، النموذج قد يخترع إحصاءات
4. **خصّص لجمهورك**، النموذج يعطي إجابات عامّة، خصّصها
5. **احفظ ما نجح**، بنك برومت شخصي = وقت موفَّر
