Midjourney أشهر أداة توليد صور فنية عالمياً. هذا الدليل يشرح التسجيل والاستخدام بلا تعقيد.

## قبل البدء

**تحتاج**:
- حساب Discord (للاستخدام التقليدي)
- **أو** حساب Google (للـweb interface الجديد)
- بطاقة ائتمان (للاشتراك)
- 15-30 دقيقة

## التسجيل

### الطريقة 1: الموقع الجديد (موصى بها)

1. اذهب إلى [midjourney.com](https://www.midjourney.com)
2. اضغط "Sign In"
3. سجّل بحساب Google أو Discord
4. اشترك في خطّة
5. جاهز، استخدم الويب مباشرة

### الطريقة 2: Discord (التقليدية)

1. أنشئ حساب Discord ([discord.com](https://discord.com))
2. اذهب إلى [midjourney.com](https://www.midjourney.com) → Sign In
3. اضبط الاشتراك
4. أُضف Midjourney Bot إلى Discord السيرفر
5. استخدم الأوامر في السيرفر

## الاشتراكات

| الخطّة | السعر | الميزات |
|---|---|---|
| **Basic** | 10$/شهر | 200 صورة سريعة، Fast |
| **Standard** | 30$/شهر | 15 ساعة Fast + Relax مجاني |
| **Pro** | 60$/شهر | 30 ساعة Fast + Stealth (خصوصية) |
| **Mega** | 120$/شهر | 60 ساعة Fast + Stealth |

**Fast** = توليد فوري (~30 ثانية)
**Relax** = يستغرق أطول لكن بلا حساب من ساعاتك

## أوّل صورة

### في الموقع

1. افتح [midjourney.com/imagine](https://www.midjourney.com/imagine)
2. اكتب برومت في الحقل
3. اضغط Enter
4. انتظر 30-60 ثانية
5. اختر من 4 نتائج

### في Discord

في أيّ قناة `#newbies-XX`:
```
/imagine prompt: قهوة سعودية عربية في دلّة تقليدية، إضاءة ذهبية دافئة، أسلوب سينمائي
```

## كتابة برومت جيّد

### البنية الأساسية

```
[الموضوع] + [التفاصيل] + [الأسلوب] + [الإضاءة] + [الكاميرا] + [Parameters]
```

**مثال**:
```
Traditional Saudi coffee (qahwa) in ornate golden dallah, cardamom pods scattered, 
warm morning light, shot on Leica 50mm, shallow depth of field, cinematic composition
--ar 16:9 --v 7 --style raw
```

### Parameters الأشهر

- `--ar 16:9`، نسبة الأبعاد (16:9, 4:3, 3:2, 1:1)
- `--v 7`، الإصدار
- `--style raw`، أسلوب طبيعي أقلّ فنيّاً
- `--stylize 100`، كم يكون فنّياً (0-1000)
- `--chaos 25`، تنوّع النتائج
- `--seed 12345`، لإعادة إنتاج نفس النتيجة

### أساليب شائعة

```
photorealistic, cinematic, portrait photography
oil painting, watercolor, digital art
anime, manga, cartoon
minimalist, brutalist, art deco
```

### إضاءة

```
golden hour, blue hour, natural light
studio lighting, moody, dramatic
neon glow, rim light, backlit
soft light, hard light
```

### كاميرا

```
shot on Leica M11, Sony A7R V, Canon EOS R5
35mm lens, 50mm portrait, 85mm bokeh
shallow depth of field, wide angle
```

## الميزات المتقدّمة

### Vary (تنويعات)

بعد توليد 4 صور، تستطيع:
- **U1/U2/U3/U4**، تكبير صورة واحدة
- **V1/V2/V3/V4**، عمل تنويعات على صورة
- **Vary (Region)**، تعديل جزء محدّد
- **Zoom Out**، توسيع الصورة
- **Pan**، تحريك الصورة يميناً/يساراً

### Image Prompts

أضف صورة كمرجع:
```
/imagine [رابط الصورة] prompt: تصميم مقهى بنفس أسلوب الصورة، سعودي حديث
```

### Style Reference (`--sref`)

```
--sref [رابط صورة]
```

يقلّد أسلوب صورة معيّنة.

### Character Reference (`--cref`)

```
--cref [رابط صورة]
```

يحافظ على نفس الشخصية عبر صور متعدّدة.

## نصائح ذهبية

1. **جرّب برومتات متعدّدة** لنفس الفكرة
2. **احفظ برومتاتك الناجحة**، بنك شخصي
3. **`--style raw` للأسلوب الطبيعي**، أقلّ فنياً
4. **`--stylize 0` لتقيّد النموذج** بالبرومت
5. جودة عالية: استخدم U (Upscale) بعد اختيار الأفضل
6. **تحقّق من الحقوق** قبل الاستخدام التجاري

## القيود

- **لا شخصيات حقيقية بأسماء**
- **قد يخطئ في اليدين والأصابع**
- **صعوبة في النصّ** داخل الصور
- **لا رقابة كاملة على النتيجة**، قد يفاجئك
- **الأشخاص العرب** قد يبدون غير طبيعيّين أحياناً

## أخطاء شائعة

### 1) برومت مبهم

"صورة جميلة" لا يعني شيئاً. حدّد.

### 2) عدم استخدام Parameters

`--ar 1:1` مربّع، `--ar 16:9` أفقي. اختر حسب الحاجة.

### 3) قبول أوّل نتيجة

اطلب V (Variations) قبل الاستقرار.

### 4) نسيان `--v 7`

بلا الإصدار، قد يستخدم إصداراً قديماً.

### 5) الاستخدام التجاري بلا اشتراك

الحقوق التجارية تحتاج اشتراكاً مدفوعاً (Basic أو أعلى).
