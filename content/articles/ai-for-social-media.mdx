كل منصّة سوشيال لها لغتها. AI يساعد لكن يجب تخصيصه. هذا الدليل يشرح لكل منصّة.

## Instagram

### Feed Posts

```
اكتب caption لصورة عن [الموضوع]:
- هوك في أوّل جملة يحمّس الحدس
- قصّة قصيرة (100-150 كلمة)
- سؤال يدعو للتعليق
- 10-15 هاشتاق مناسب
```

**الأدوات**:
- ChatGPT للنصّ
- DALL-E/Midjourney للصور
- Canva للتصميم
- Buffer/Later للجدولة

### Stories

- توليد Polls (ChatGPT)
- أسئلة تفاعلية
- Countdown stickers
- Behind-the-scenes نصوص

### Reels

```
اكتب سكريبت Reel 30 ثانية عن [الموضوع]:
- Hook (3 ثوانٍ صادم)
- محتوى (25 ثانية، 3 نقاط)
- CTA (2 ثانية)
لغة محكية سريعة.
```

**التحرير**: CapCut (مع أدوات AI مدمجة).

## TikTok

### أنواع محتوى شهيرة

- **Educational** (تعليمي سريع)
- **Trend-based** (يتبع اتّجاهات)
- **Story-time** (قصص شخصية)
- **POV** (منظور)
- **Duets/Stitches** (تفاعل مع محتوى غيرك)

### كتابة سكريبت TikTok

```
اكتب TikTok 45 ثانية بأسلوب Story-time:
- الموضوع: [صف]
- الشخصية: أنا (30 سنة، مسوّق سعودي)
- Twist في المنتصف
- درس في النهاية
لغة محكية سعودية، بلا رسمية.
```

### Hashtags

```
اقترح 15 هاشتاق TikTok لفيديو عن [الموضوع]:
- 3 عامّة (رواج)
- 8 متخصّصة (Niche)
- 4 محلية (سعودية).
```

## LinkedIn

### المنشور الأمثل

```
اكتب منشور LinkedIn 200 كلمة عن [الموضوع]:
- هوك تصدم في السطر الأوّل (لا "في هذا العالم")
- قصّة شخصية بتفصيل محدّد
- درس واحد
- سؤال يدعو للتعليق
- لا هاشتاق أكثر من 3
- لا إيموجي أكثر من 2
```

### أنواع منشورات ناجحة

- **Storytelling**، قصّة شخصية بدرس
- **Contrarian**، رأي مخالف للسائد
- **Frameworks**، إطار عمل قابل للتطبيق
- **Case Studies**، أمثلة عملية
- **Data**، رقم صادم + شرحه

### Carousels (متعدّد الشرائح)

```
صمّم Carousel LinkedIn 8 شرائح عن [الموضوع]:
- شريحة 1: عنوان جذّاب + سؤال يعد بحلّ
- شرائح 2-7: نقاط، كل واحدة قصيرة
- شريحة 8: خلاصة + CTA + سؤال
```

**التصميم**: Canva

## X (Twitter)

### تغريدة قوية

```
اكتب 10 تغريدات عن [الموضوع]:
- 5 بيانات صادمة
- 3 آراء جريئة
- 2 أسئلة استفزازية
كل تغريدة تحت 280 حرف.
```

### ثريد X

```
اكتب ثريد X من 10 تغريدات عن [الموضوع]:
- تغريدة 1: هوك يجذب النقر لقراءة الثريد
- تغريدات 2-9: نقاط، كل واحدة تُبنى على السابقة
- تغريدة 10: خلاصة + CTA
```

### Reply Strategy

- علّق بقيمة، لا "متفق"
- اذكر رأياً مختلفاً بأدب
- Engage مع الحسابات الكبيرة بذكاء

## YouTube

### أنواع

**Long-form** (10+ دقيقة): سكريبت مفصّل، ThumbnailAI، عنوان SEO
**Shorts** (&lt;60 ثانية): سكريبت سريع، بلا مقدّمة

### عنوان يجذب

```
اكتب 15 عنواناً ليوتيوب عن [الموضوع]:
- تحت 60 حرف
- CTR عالٍ
- بلا خداع
- خليط: فضول، فائدة، عاطفي.
```

### Thumbnail

```
[DALL-E]
Thumbnail for YouTube video about [الموضوع]:
- Bright colors, bold text
- Text overlay: '[3-5 كلمات صادمة]'
- Photorealistic style
- High contrast
1280x720
```

### الوصف

```
اكتب وصف يوتيوب عن [الموضوع]:
- سطران يعرّفان + كلمة مفتاحية
- وصف مفصّل 200 كلمة
- Timestamps
- Links
- 10-15 هاشتاق.
```

## Facebook

- منشورات أطول تعمل أفضل من X
- الروابط قد تُعاقب، استخدم Native content
- Groups فعّالة للـniche

### كتابة منشور

```
اكتب منشور Facebook 250 كلمة عن [الموضوع]:
- افتتاحية شخصية
- قصّة محدّدة
- درس عملي
- سؤال يفتح حواراً.
```

## Threads (Instagram)

- لغة محادثة يومية
- بدون هاشتاق أو إيموجي مفرط
- يكافئ الأصالة

```
اكتب بوست Threads عن [الموضوع]:
- 2-3 جمل
- شخصي، غير رسمي
- بلا هاشتاق.
```

## استراتيجية Cross-Platform

**فكرة واحدة، منصّات متعدّدة**:

1. **فيديو يوتيوب 10 دقائق** (المحتوى الأصلي)
2. **Shorts/Reels 60 ثانية** (Highlight)
3. **Carousel LinkedIn 8 شرائح** (Frameworks)
4. **ثريد X 10 تغريدات** (Points)
5. **منشور Instagram** (Quote graphic)
6. **مقال LinkedIn/Blog** (Long-form)
7. **إيميل نيوزلتر** (Summary + link)

**Opus Clip أو Descript** يساعدان في تحويل الطويل إلى قصير.

## متى الإفصاح ضروري؟

| المنصّة | الإفصاح |
|---|---|
| **YouTube** | إجباري إذا فيديو يبدو واقعياً |
| **TikTok** | إجباري (زرّ في المحرّر) |
| **Meta/Instagram** | إجباري للأشخاص/الأحداث الحقيقية |
| **X** | ليس إجبارياً |
| **LinkedIn** | ليس إجبارياً، لكن ينصح به |

## نصائح ذهبية

1. **صوتك مصدر تفوّقك**، AI للسرعة، أنت للأصالة
2. **جودة > كمّية**، 3 منشورات ممتازة > 20 متوسّط
3. **الاتّساق أهمّ من الكمال**، انشر بانتظام
4. **التفاعل الحقيقي**، رد على تعليقات بنفسك
5. **راقب المنافسة**، تعلّم من الناجحين
6. **AI + إنسان = التركيبة الفائزة**
