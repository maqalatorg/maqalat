الطالب الذكي يستخدم AI **ليتعلّم أفضل**، لا **ليتعلّم أقلّ**. هذه 25 برومت تحوّل ChatGPT إلى مدرّس خاصّ ومساعد مذاكرة.

## للفهم (5 برومتات)

### 1) اشرح مفهوماً بمستوى

```
اشرح لي مفهوم [X] وكأنّي [الصف الأوّل / السادس / ثانوي / جامعي].
- ابدأ بتشبيه من الحياة اليومية
- مثال ملموس
- تحذير من مفهوم خاطئ شائع
- جملة واحدة أتذكّرها.
```

### 2) اشرح بـ3 طرق

```
اشرح مفهوم [X] بـ3 طرق مختلفة:
- بلغة بسيطة
- بمثال ملموس
- بمعادلة أو رسم بياني وصفي.
```

### 3) لماذا هذا مهمّ

```
لماذا مفهوم [X] مهمّ في [المجال]؟
- تطبيق واحد يومي
- تطبيق مهني
- علاقته بمفاهيم أخرى في المادّة.
```

### 4) الفروقات

```
ما الفرق بين [A] و[B]؟
- تعريف كل واحد بجملة
- جدول 5 فروق
- متى نستخدم كلّاً
- خطأ شائع في الخلط بينهما.
```

### 5) تشبيه للحفظ

```
اعطني تشبيهاً أتذكّر به مفهوم [X].
التشبيه من الحياة اليومية.
اشرح كل جزء من التشبيه ما يقابل في المفهوم.
```

## للتلخيص (5 برومتات)

### 6) تلخيص فصل كتاب

```
لخّص هذا الفصل: [ألصق].
البنية:
- الفكرة الرئيسية بجملة
- 5 نقاط أساسية
- المصطلحات المهمّة (5)
- سؤال يقيس فهمي.
```

### 7) خريطة ذهنية

```
حوّل هذا النصّ إلى خريطة ذهنية نصية: [ألصق].
- المركز: المفهوم الأمّ
- 5 فروع رئيسية
- كل فرع تحته 3 نقاط تفصيلية.
```

### 8) بطاقات مذاكرة (Flashcards)

```
اكتب 20 بطاقة مذاكرة من هذا النصّ: [ألصق].
كل بطاقة: سؤال في السطر الأوّل، جواب في السطر الثاني.
مستوى الأسئلة متدرّج.
```

### 9) ملخّص للمراجعة السريعة

```
اكتب ملخّصاً للمراجعة السريعة قبل الامتحان لهذه المادّة: [ألصق].
- طوله لا يتجاوز صفحة واحدة
- تعاريف مركّزة
- صيغ رياضية إن وُجدت
- 3 أمثلة شهيرة.
```

### 10) ملخّص محاضرة

```
لخّص محاضرة من ملاحظاتي: [ألصق].
البنية: الموضوع الرئيسي، 3 أفكار مركزية، جدول مفاهيم، أسئلة توقّع من الأستاذ.
```

## للتدريب (5 برومتات)

### 11) أسئلة تدريب

```
اكتب لي 15 سؤال تدريب على [الموضوع].
- 5 سهلة
- 5 متوسّطة
- 5 صعبة
لا تُعطِ الأجوبة. سأحلّها ثمّ أعطيك للتصحيح.
```

### 12) تصحيح إجاباتي

```
هذه أسئلتي وإجاباتي: [ألصق].
- صحّح كل إجابة (صحيحة / خاطئة / جزئية)
- اشرح الجواب الصحيح
- درجات لكل سؤال من 10.
```

### 13) امتحان تجريبي

```
اكتب لي امتحان تجريبي في [المادّة].
البنية:
- 10 اختيار من متعدّد (4 خيارات)
- 5 صواب/خطأ
- 3 أسئلة مقالية قصيرة
مدّة الامتحان: 90 دقيقة.
```

### 14) مسائل رياضية متدرّجة

```
اكتب لي 10 مسائل [نوع الرياضيات: تفاضل، إحصاء، إلخ]:
- 3 سهلة (تطبيق مباشر)
- 4 متوسّطة (تطبيق + تفكير)
- 3 صعبة (تحليل).
لا حلول. سأحلّها ثمّ أرسلها للتصحيح.
```

### 15) تعلّم بالممارسة

```
علّمني [المفهوم] بالممارسة:
1. تشرحه بمثال
2. تعطيني تمريناً مشابهاً
3. أحلّه وترسل التصحيح
4. تمرين أصعب
5. حلّي وتصحيح
6. تمرين تطبيقي على واقع.
```

## للكتابة الأكاديمية (5 برومتات)

### 16) خطّة بحث

```
اكتب خطّة بحث لـ[الموضوع].
البنية:
- عنوان مقترَح
- سؤال البحث
- أهدافه
- المقدّمة (نقاط)
- الفصل 1، 2، 3 (نقاط لكل فصل)
- الخاتمة
- 10 مراجع مقترَحة (يمكن الاختراع للتدريب، سأتحقّق).
```

### 17) مراجعة كتابتي (لا كتابتها)

```
هذا مقالي الأكاديمي: [ألصق].
راجعه على:
- بنية الحجّة
- قوّة الأدلّة
- الوضوح
- الأخطاء اللغوية
- الاقتراحات لتحسينه.
لا تُعِد كتابته. أعطني ملاحظات.
```

### 18) تنسيق مصادر (APA/MLA)

```
هذه مصادري: [ألصق].
حوّلها إلى تنسيق [APA / MLA / Chicago] الصحيح.
تحقّق من الصيغة بدقّة.
```

### 19) مقدّمة بحث

```
اكتب مقدّمة أكاديمية 300 كلمة لبحث عن [الموضوع].
البنية: هوك، خلفية عامّة، فجوة بحثية، سؤال البحث، أهمّية البحث، ما يغطّيه هذا البحث.
```

### 20) مناقشة نتائج

```
هذه نتائجي: [ألصق].
اكتب قسم "المناقشة" 500 كلمة.
البنية: تفسير النتائج، مقارنة بأبحاث سابقة (تحفّظ لو لم يكن لديك مصادر)، محدودية الدراسة.
```

## لتعلّم اللغات (5 برومتات)

### 21) محادثة تفاعلية

```
دعنا نتحاور بالإنجليزية:
- أنا مستوى [Beginner / Intermediate / Advanced]
- الموضوع: [حياة يومية / أعمال / سفر]
- كل مرّة أرد، صحّح أخطائي (بلطف)، اقترح جملة أفضل، ثمّ أكمل الحوار.
```

### 22) شرح قاعدة نحوية

```
اشرح لي قاعدة [Past Perfect / Subjunctive / إلخ] بالإنجليزية.
- التعريف بجملة
- التركيب
- 5 أمثلة
- 3 أخطاء شائعة
- تمرين.
```

### 23) توسيع المفردات

```
علّمني 20 كلمة إنجليزية جديدة عن [الموضوع].
كل كلمة:
- المعنى بالعربية
- جملة استخدام
- كلمة قريبة معناها (synonym)
- كلمة عكسها (antonym).
```

### 24) قصّة قصيرة للتعلّم

```
اكتب قصّة قصيرة 300 كلمة بالإنجليزية بمستوى [Intermediate].
استخدم أفعالاً في زمن [Past Tense].
بعد القصّة:
- قائمة الكلمات الصعبة مع الترجمة
- 5 أسئلة فهم.
```

### 25) اختبار مفرداتي

```
اختبرني على [Vocabulary] بأسلوب:
- سؤال (باللغة الإنجليزية أو العربية)
- أنتظر إجابتي
- تصحيح فوري + جملة استخدام صحيحة
- سؤال أصعب.
عشرة أسئلة، تدرّج في الصعوبة.
```

## نصائح للاستخدام السليم

1. **AI مساعد، لست بديل**، لا تنسخ إجابات كأنّها لك
2. **راجع كل حقيقة**، النموذج يخطئ في التفاصيل الأكاديمية
3. **استخدمه للفهم لا للتذكّر**، الحفظ يبقى وظيفتك
4. **اعرف سياسة جامعتك**، بعض الجامعات تشترط الإفصاح
5. **لا ترفع إجابات امتحانات**، قد يكون خرقاً أخلاقياً
