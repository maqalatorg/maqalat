المسوّق الذكي في 2026 يستخدم ChatGPT كأداة قوّة تكبّر إنتاجه. هذا الدليل يشرح كيف بأمثلة عملية سعودية.

## للاستراتيجية

### 1) بناء ICP (Ideal Customer Profile)

```
حدّد لي ICP لخدمة استشارات تسويق رقمي في السعودية:
- الديموغرافيا (مدراء تسويق 30-45 سنة)
- Psychographics (طموحون، يعانون من ضغط النتائج)
- سلوك (ينشط على LinkedIn، يحضر مؤتمرات)
- نقاط الألم (عائد استثمار غير واضح، ضغط الميزانية)
- ما يقنعهم بالشراء.
```

### 2) SWOT للحملة

```
حلّل SWOT لحملة تسويقية لعلامة [X] تدخل السوق السعودي:
- Strengths (5)
- Weaknesses (5)
- Opportunities (5)
- Threats (5)
اذكر الفرصة الأهمّ.
```

### 3) تحليل منافسين

```
هذه معلومات عن 3 منافسين: [ألصق].
حلّل:
- استراتيجية كل منافس
- نقاط قوّتهم
- ثغرات نستغلّها
- تسعيرهم مقارنة.
```

## للمحتوى

### 4) توليد أفكار محتوى

```
اقترح 30 فكرة محتوى شهرياً لعلامة قهوة سعودية:
- 10 تعليمية (كيف تُختار حبوب)
- 10 قصص عملاء
- 10 خلف الكواليس
كل فكرة: عنوان + خط سرد.
```

### 5) كتابة إعلانات Meta

```
اكتب 5 إعلانات Meta لمنتج [X]:
- الجمهور: [صف]
- الهدف: conversions
- كل إعلان: هوك (سطر)، فائدة (سطران)، CTA.
- تجنّب كلمات ممنوعة (100%، مضمون).
```

### 6) كتابة Google Ads

```
اكتب 15 headline (تحت 30 حرف) + 4 description (تحت 90 حرف) لـGoogle Search Ads تستهدف الكلمة [X].
```

### 7) نصّ فيديو TikTok

```
اكتب سكريبت TikTok 30 ثانية لـ[المنتج]:
- هوك (3 ثوانٍ صادم)
- مشكلة (10 ثوانٍ)
- حلّ = منتجنا (15 ثانية)
- CTA (2 ثانية).
لغة محكية سريعة.
```

### 8) مقال بلوق SEO

```
اكتب مقال بلوق 1500 كلمة يستهدف كلمة [X]:
- الكلمة في العنوان + أوّل 100 كلمة
- 5 عناوين H2 (كل يحوي كلمة LSI)
- FAQ 5 أسئلة
- 3 روابط داخلية، 2 خارجية.
```

## لتحليل العملاء

### 9) تحليل مراجعات

الصق 100 مراجعة، اطلب:

```
- 5 شكاوى أكثر تكراراً
- 5 مدائح أكثر تكراراً
- 3 اقتراحات تحسين واضحة
- ملاحظة عامّة عن تجربة العميل.
```

### 10) تصنيف Leads

```
هذه قائمة Leads: [ألصق].
صنّف كل واحد:
- Hot (جاهز للشراء)
- Warm (يحتاج متابعة)
- Cold (لا اهتمام واضح)
بناءً على سلوكه.
```

### 11) رسائل مخصّصة للعملاء

```
اكتب 20 رسالة إيميل مخصّصة لعملاء [قائمة]:
كل واحد بناءً على تاريخ شرائه، ذكر منتجه، عرض ذات صلة.
```

## للتحليل

### 12) تحليل حملة سابقة

```
هذه بيانات حملة: [ألصق].
حلّل:
- ROI
- أفضل قناة
- أسوأ قناة
- 3 توصيات للحملة القادمة.
```

### 13) توقّع اتّجاهات

```
حسب هذه البيانات التاريخية: [ألصق].
- ما الاتّجاه المتوقّع للربع القادم؟
- عوامل قد تُغيّره؟
- 3 سيناريوهات (متفائل، متحفّظ، محافظ).
```

### 14) تحليل A/B

```
هذه نتائج A/B Test:
Variant A: 15% conversion، 1000 visitor
Variant B: 18% conversion، 1000 visitor
- هل الفرق ذو دلالة إحصائية؟
- ما التوصية؟
- ما ينبغي اختباره تالياً؟
```

## للـSEO

### 15) بحث كلمات مفتاحية

```
اقترح 30 كلمة مفتاحية لمتجر [منتج] في السعودية:
- 10 head keywords
- 15 long-tail
- 5 questions
مع تقدير قصد البحث.
```

### 16) تحسين meta

```
اكتب 5 meta title (60 حرف) + 5 meta description (155 حرف) لصفحة عن [الموضوع].
- الكلمة المفتاحية في أوّل 30 حرف
- CTA طبيعي في الوصف.
```

### 17) Featured Snippet

```
اكتب فقرة 40-60 كلمة تجيب على السؤال [X] لاستهداف Featured Snippet.
- إجابة مباشرة أوّلاً
- تفاصيل داعمة.
```

## للتفاعل

### 18) ردود على تعليقات

```
هذه تعليقات إيجابية وسلبية: [ألصق].
اقترح ردوداً:
- الإيجابية: شكر بأصالة، سؤال لاستمرار الحوار
- السلبية: تعامل مهني، اعتراف إن صحّ، حلّ.
```

### 19) نشر جماعي

```
اكتب 30 منشوراً لـInstagram Stories لأسبوع:
- 5 استفتاءات
- 5 أسئلة
- 5 اقتباسات
- 5 خلف الكواليس
- 5 منتجات
- 5 قصص عملاء.
```

### 20) دعوات للمناسبات

```
اكتب رسائل دعوة لحدث [الاسم]:
- LinkedIn (مهني)
- WhatsApp (شخصي)
- Email (رسمي)
- Instagram Story (بصري).
```

## Custom GPTs للمسوّق

بنِ 5 GPTs مخصّصة:

1. **كاتب سوشيال بأسلوب علامتك**
2. **محلّل مراجعات**
3. **مسوّغ حملات**
4. **مصحّح Meta Ads** (ينبّه للكلمات الممنوعة)
5. **محلّل منافسين**

## أدوات مكمّلة

- **Canva**، تصميم بصري
- **Buffer**، جدولة سوشيال
- **HubSpot**، CRM + Marketing
- **SEMrush**، SEO + Ads
- **Zapier**، أتمتة

## نصائح ذهبية

1. **AI للسرعة، أنت للاستراتيجية**
2. **راجع كل مخرج قبل النشر**، النموذج قد يخترع أرقاماً
3. **حافظ على صوت العلامة**، لا تجعله يذوب
4. **اختبر A/B دائماً**، لا تصدّق مخرج AI بلا بيانات
5. **بنك برومت شخصي**، كل مسوّق ناجح لديه واحد
