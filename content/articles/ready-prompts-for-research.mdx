الباحث الذكي في 2026 يستخدم AI ليختصر الوقت الروتيني، لا ليختصر التفكير. هذه 20 برومت لكل مرحلة بحث.

## للأدبيات (5 برومتات)

### 1) خطّة مراجعة أدبيات

```
أكتب مراجعة أدبيات لموضوع: [X].
- اقترح 8-10 محاور رئيسية
- ترتيب المحاور منطقياً
- ما الفجوات المتوقّعة
- 15 مصطلح بحث (بالإنجليزية) لأبحث بها.
```

### 2) تلخيص ورقة

```
هذه ورقة علمية: [ألصق abstract أو النصّ].
اكتب ملخّصاً:
- السؤال البحثي
- المنهج
- النتائج الرئيسية
- المحدوديّات
- التطبيقات
- كيف يخدم بحثي عن [Y]؟
```

### 3) مقارنة أوراق

```
هذه 3 أوراق: [ألصق ملخّصاتها].
قارنها:
- التقارب في النتائج
- التباعد
- المنهجيات المختلفة
- أيّها أقوى methodologically ولماذا.
```

### 4) توليد سؤال بحث

```
لموضوع [X]، اقترح 10 أسئلة بحثية:
- 5 وصفية
- 3 علاقة (correlation)
- 2 سببية (causal)
كل سؤال يشمل: المتغيّرات، الجمهور، النطاق.
```

### 5) تحديد فجوة بحثية

```
هذه ملخّصات لأهمّ 10 دراسات في المجال: [ألصق].
- ما الفجوات البحثية؟
- ما لم يُجَب عليه بعد؟
- 3 أسئلة بحث محتملة تسدّ الفجوة.
```

## للمنهجية (5 برومتات)

### 6) اختيار منهج

```
سؤال بحثي: [ألصق].
اقترح المنهج الأنسب:
- كمّي / نوعي / مختلط
- تصميم البحث (Experimental، Correlational، Case Study، إلخ)
- أدوات جمع البيانات
- تحليل مناسب
- حجم عيّنة أوّلي.
```

### 7) استبيان بحثي

```
لسؤال بحثي: [X]، اكتب استبياناً:
- 20 سؤالاً مقسّمة (ديموغرافيا، متغيّرات، مخرجات)
- مزيج: Likert scale، اختيار من متعدّد، مفتوح
- ترتيب منطقي
- كل سؤال يقيس متغيّراً محدّداً.
```

### 8) دليل مقابلة (Interview Guide)

```
لدراسة نوعية عن [X]، اكتب دليل مقابلة نصف-مهيكلة:
- 3 أسئلة تمهيدية
- 8-10 أسئلة رئيسية (Open-ended)
- Probes لكل سؤال رئيسي
- سؤال ختامي.
```

### 9) خطّة تحليل بيانات

```
لجمع بيانات:
- كمّية: [صف: عدد المشاركين، المتغيّرات]
- نوعية: [صف]
اقترح:
- الاختبارات الإحصائية المناسبة
- برامج (SPSS، R، Python)
- طرق التحليل النوعي (Thematic، Content Analysis)
- خطوات التحليل بالترتيب.
```

### 10) اعتبارات أخلاقية

```
لبحث عن [الموضوع، الجمهور، الطريقة]:
- ما الاعتبارات الأخلاقية؟
- ما موافقات لجنة الأخلاق (IRB) المطلوبة؟
- Informed Consent template
- حماية بيانات المشاركين.
```

## للكتابة (5 برومتات)

### 11) هيكل ورقة IMRAD

```
اكتب هيكل ورقة IMRAD (Introduction, Methods, Results, Discussion) لبحث عن [X].
- Introduction: 3 أقسام (background, gap, research question)
- Methods: تفاصيل بالنقاط
- Results: كيف تُنظّم النتائج
- Discussion: 4 محاور.
```

### 12) مقدّمة بحث

```
اكتب مقدّمة أكاديمية 500 كلمة لبحث عن [X]:
- Hook (فقرة)
- Background (فقرتان)
- Gap in literature (فقرة)
- Research question and objectives
- Significance
- Structure of paper.
```

### 13) نقاش نتائج

```
هذه نتائج بحثي: [ألصق].
اكتب قسم Discussion 800 كلمة:
- تفسير النتائج الرئيسية
- مقارنة بأبحاث سابقة (بمصادر — تحقّق بشرياً)
- التطبيقات (Implications)
- المحدودية (Limitations)
- Future Research.
```

### 14) خلاصة (Abstract)

```
هذا بحثي الكامل: [ألصق ملخّص].
اكتب Abstract 250 كلمة بأسلوب:
- Background (2-3 جمل)
- Objective (جملة)
- Methods (2-3 جمل)
- Results (2-3 جمل)
- Conclusion (2 جمل).
```

### 15) عنوان ورقة

```
اكتب 10 عناوين محتملة لبحثي عن [الموضوع الدقيق].
- كل عنوان دقيق وواضح
- يحوي المتغيّرات الرئيسية
- تحت 15 كلمة
- بلا مبالغة.
```

## للمراجعة والنشر (5 برومتات)

### 16) مراجعة قواعد نحوية

```
راجع بحثي أكاديمياً: [ألصق].
- الأخطاء النحوية
- الصياغة (Passive vs Active)
- التماسك بين الفقرات
- مصطلحات غير دقيقة.
لا تُعِد الكتابة — أعطني ملاحظات.
```

### 17) مراجعة اقتباسات

```
هذه اقتباساتي: [ألصق قائمة].
- التنسيق [APA/MLA/Chicago] صحيح؟
- هل تنقص معلومات؟
- هل الأسلوب متّسق؟
```

### 18) اقتراح مجلّة

```
بحثي عن [الموضوع، المنهج، الجمهور]:
اقترح 10 مجلّات علمية للنشر:
- اسم المجلّة
- Impact Factor تقديري
- نطاق قبولها
- نسبة قبول تقديرية
- Open Access؟
تحقّق بشرياً من كل مجلّة.
```

### 19) رسالة تعريف (Cover Letter)

```
اكتب Cover Letter لمحرّر مجلّة [X] لتقديم ورقة عن [Y].
- تعريف بالبحث بجملتَين
- لماذا مناسب للمجلّة
- Contribution to field
- Confirmations (لم يُنشر، لا تضارب مصالح، إلخ).
```

### 20) رد على مراجعي أقران

```
هذا رد المراجعين: [ألصق].
اكتب Response Letter:
- شكر مهذّب
- لكل ملاحظة: رد نقطة نقطة
- التغييرات التي أجريناها (إن وجدت)
- التغييرات التي لم نجرها ولماذا (بأدب).
```

## قواعد أخلاقية

1. **الإفصاح**: أخبر مشرفك/الناشر باستخدام AI
2. **الأصالة**: الأفكار المركزية لك، AI للأدوات المساعدة
3. **المصادر**: تحقّق يدوياً من كل مصدر
4. **البيانات**: لا ترفع بيانات مشاركين لـChatGPT العادي
5. **المسؤولية**: أيّ ادّعاء علمي في ورقتك — مسؤوليتك أنت

## أدوات بحثية موصى بها

- **NotebookLM** — تحمّل PDFs، اسأل، اقتبس
- **Perplexity Pro** — بحث بمصادر
- **Scholar GPT** — GPT مخصّص لـScholar
- **Zotero** — إدارة مراجع
- **Grammarly Academic** — تدقيق أكاديمي
