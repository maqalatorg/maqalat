صانع المحتوى الذكي في 2026 ينتج 5x بجودة أفضل. المفتاح: AI للأجزاء المتكرّرة، أنت للأصالة والصوت.

## للأفكار (5 برومتات)

### 1) عصف ذهني أفكار

```
اقترح 30 فكرة فيديو يوتيوب لقناتي عن [الموضوع].
جمهوري: [صف].
مقسّمة:
- 10 تعليمية
- 10 مثيرة للتفاعل (رأي، سؤال)
- 10 خلف الكواليس (شخصية)
كل فكرة: عنوان مقترَح، جملة تشرحها.
```

### 2) اتّجاهات المجال

```
ما اتّجاهات محتوى [المجال] في 2026؟
- 10 مواضيع رائجة الآن
- 5 مواضيع صاعدة
- 3 قد تصير رائجة قريباً.
```

### 3) تحويل مقال لسلسلة محتوى

```
هذا مقال طويل: [ألصق].
حوّله إلى:
- 5 فيديوهات قصيرة (شرح كل نقطة)
- 20 منشور سوشيال
- ثريد X من 10 تغريدات
- بودكاست 15 دقيقة (نقاط).
```

### 4) أفكار من تعليقات جمهورك

```
هذه تعليقات جمهوري: [ألصق].
- ما الأسئلة المتكرّرة؟
- ما المشاكل الشائعة؟
- 10 أفكار محتوى من هذه التعليقات.
```

### 5) أفكار من منافسك

```
هذه قائمة أعلى فيديوهات منافسي [X] أداءً: [ألصق].
- ما الأنماط المشتركة؟
- ما لم يغطّه بعد؟
- 5 أفكار أفضل بزوايا مختلفة.
```

## للسكريبتات (5 برومتات)

### 6) سكريبت فيديو يوتيوب طويل

```
اكتب سكريبت فيديو يوتيوب 10 دقائق عن [الموضوع].
البنية:
- Hook (30 ثانية): بيان صادم، لا مقدّمة طويلة
- مقدّمة (30 ثانية): من أنا، ماذا سأشرح
- محتوى (8 دقائق): 3-5 نقاط، كل نقطة قصّة/مثال
- خاتمة (60 ثانية): ملخّص، CTA
لغة محكية طبيعية، ليس رسمية.
```

### 7) سكريبت Short/Reel

```
اكتب سكريبت فيديو قصير 45 ثانية عن [الموضوع].
البنية:
- Hook (5 ثوانٍ): يجذب فوراً
- بناء توتّر (10 ثوانٍ)
- الذروة/الفكرة (25 ثانية)
- خاتمة سريعة + CTA (5 ثوانٍ)
لغة سريعة، جمل قصيرة.
```

### 8) سكريبت TikTok Educational

```
اكتب سكريبت TikTok تعليمي 60 ثانية عن [مفهوم].
- افتتاحية تصدم بسؤال
- شرح بمثال يومي
- Punchline في النهاية
- CTA (لمزيد، تابع).
```

### 9) سكريبت بودكاست

```
اكتب Notes لحلقة بودكاست 30 دقيقة عن [الموضوع].
البنية:
- Cold Open (30 ثانية)
- ترحيب (30 ثانية)
- 3 محاور رئيسية (كل واحد 8 دقائق) بنقاط الحوار
- Ad Break (اختياري)
- خاتمة + CTA (60 ثانية).
```

### 10) Voiceover نصّ

```
اكتب voiceover 60 ثانية لفيديو عن [الموضوع].
- لغة عربية فصحى مبسّطة
- إيقاع سردي
- كلمات سهلة النطق
- بلا مصطلحات تقنية معقّدة.
```

## للعناوين والوصف (5 برومتات)

### 11) عناوين يوتيوب مغرية

```
اكتب 15 عنواناً لفيديو يوتيوب عن [الموضوع].
- تحت 60 حرف
- CTR-optimized
- بلا خداع (Clickbait ممنوع)
- 5 استعمال فضول، 5 وعد فائدة، 5 عاطفي.
```

### 12) وصف يوتيوب SEO

```
اكتب وصف فيديو يوتيوب عن [الموضوع]:
- أوّل سطرَين يشرحان الفيديو + الكلمة المفتاحية
- وصف مفصّل 200 كلمة
- Timestamps للأقسام
- Links المذكورة
- 10-15 هاشتاق.
```

### 13) عناوين مقالات

```
اكتب 20 عنواناً لمقال بلوق عن [الموضوع].
- 10 عناوين قوائم (5 أخطاء، 10 نصائح)
- 5 عناوين أسئلة
- 5 عناوين "كيف تفعل".
```

### 14) Captions Instagram

```
اكتب 3 captions مختلفة لصورة عن [الموضوع]:
- قصير (50 كلمة): مباشر
- متوسّط (100 كلمة): قصّة قصيرة
- طويل (200 كلمة): تعليمي مع سؤال
كلها تدعو للتعليق.
```

### 15) Thumbnails ideas

```
اقترح 5 أفكار thumbnails لفيديو عن [الموضوع].
- وصف بصري لكل thumbnail
- النصّ المكتوب عليه (3-5 كلمات)
- الأسلوب (عاطفي، عصري، فكاهي).
```

## للتفاعل (5 برومتات)

### 16) ردود على التعليقات

```
هذه تعليقات على منشوري: [ألصق].
اقترح ردوداً:
- إيجابي: كيف أشكر بأصالة
- سؤال: جواب مختصر + دعوة للاستمرار
- سلبي: كيف أرد بمهنية بدون دفاعية.
```

### 17) أسئلة تدعو للتفاعل

```
اقترح 20 سؤالاً لجمهوري في [الموضوع]:
- 10 نعم/لا
- 5 اختيار من 2 (هذا أم ذاك)
- 5 مفتوحة تدعو للحوار.
```

### 18) Polls على Instagram Stories

```
اكتب 10 polls لـInstagram Stories عن [الموضوع]:
- كل poll: السؤال + خيارَين
- تحفّز التفاعل
- تعطيني بيانات مفيدة عن جمهوري.
```

### 19) Community Post

```
اكتب Community Post ليوتيوب/Facebook Group:
- الموضوع: [X]
- الهدف: تفاعل عالٍ
- 100 كلمة كأقصى
- ينتهي بسؤال أو استفتاء.
```

### 20) رد على منتقد

```
هذا منتقد في تعليقات: [ألصق].
اكتب رداً:
- مهني، بلا دفاعية
- اعتراف بالنقطة الصحيحة إن وجدت
- توضيح للنقاط الخاطئة بأدب
- خاتمة تُغلق النقاش.
```

## للاستراتيجية (5 برومتات)

### 21) خطّة نمو 90 يوم

```
صمّم خطّة نمو 90 يوم لقناتي عن [الموضوع].
حاليّاً: [عدد المتابعين، الأداء].
الهدف: [مضاعفة، وصول X].
الخطّة:
- محتوى (كم فيديو أسبوعياً)
- تنويع الأشكال (طويل، short، لايف)
- تعاونات
- تحسينات تقنية
- KPIs أسبوعية.
```

### 22) تحليل قناة منافس

```
حلّل قناة منافسي [الاسم]:
- ما يعمل عندهم (أنواع فيديو، عناوين، thumbnails)
- ما لا يعمل
- ما فرصهم المفقودة
- كيف أفوز عليهم.
```

### 23) استراتيجية Cross-Platform

```
لدي محتوى يوتيوب. كيف أعيد استخدامه:
- Instagram (Reels, Stories, Posts)
- TikTok
- X (Threads, Regular Tweets)
- LinkedIn
- Newsletter
بأقلّ جهد إضافي.
```

### 24) Content Pillars

```
اقترح 4-5 Content Pillars لقناتي عن [المجال].
لكل pillar:
- الوصف
- أنواع المحتوى داخله
- كم % من نشاطي يخصّه
- KPI رئيسي.
```

### 25) Monetization Strategy

```
قناتي: [عدد متابعين، مجال، نوع محتوى].
اقترح 5 طرق للتحقيق:
- الأنسب لحجم قناتي
- كم يتوقّع منها
- كيف أبدأ
- ما المخاطر.
```

## نصائح ذهبية

1. **AI للأجزاء المتكرّرة، أنت للأصالة** — سكريبت مسوّدة، ليس نهائي
2. **صوتك الأصلي مصدر تفوّقك** — لا تنسخ ولا تقلّد
3. **راجع كل حقيقة** — النموذج يخترع أحياناً
4. **تكيّف مع منصّتك** — TikTok ≠ LinkedIn
5. **اختبر A/B** — عناوين، thumbnails، أشكال
