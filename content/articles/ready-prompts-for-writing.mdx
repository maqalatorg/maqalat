مكتبة عملية من 50 برومت اختُبرت للكتابة العربية. مصنّفة حسب النوع، جاهزة للنسخ.

## للمقالات (10 برومتات)

### 1) مقال معلوماتي شامل

```
اكتب مقالاً 1500 كلمة عن [الموضوع].
الجمهور: [حدّد].
الأسلوب: صحفي معاصر، جمل قصيرة، بلا كليشيهات.
البنية: مقدّمة صادمة (لا "في هذا العالم")، 5 عناوين H2، جدول واحد على الأقل، خلاصة قوية.
اذكر 3 مصادر رسمية موثّقة بروابطها.
```

### 2) مقال مقارنة

```
اكتب مقال مقارنة بين [A] و[B] لجمهور [صف].
البنية: جدول مقارنة 8 معايير، فقرات لكل معيار، توصية نهائية "أيّهما لك".
```

### 3) مقال قصّة نجاح

```
اكتب مقال قصّة نجاح لـ[الاسم/الشركة].
البنية: هوك يشدّ (رقم صادم أو مفارقة)، البداية (الظرف الصعب)، التحدّي، الحلّ، النتيجة، الدرس.
اجعله شخصياً بلا كليشيهات.
```

### 4) مقال "كيف تفعل"

```
اكتب مقال "كيف تفعل [X]".
البنية: هوك، فوائد النتيجة، الخطوات (10 خطوات مرقّمة)، أخطاء تجنّبها، توصية عملية.
كل خطوة 100-150 كلمة، عملية قابلة للتنفيذ.
```

### 5) مقال قائمة (Listicle)

```
اكتب مقال "[الرقم] أفضل [الفئة] في [السياق]".
كل عنصر بعنوان، وصف 100 كلمة، سبب إدراجه، رابط أو مرجع.
```

### 6) مقال دراسة حالة

```
اكتب دراسة حالة عن [العميل/المشروع].
البنية: نظرة عامّة، المشكلة، الحلّ، التنفيذ، النتائج بأرقام، الدروس، توصيات.
```

### 7) مقال رأي

```
اكتب مقال رأي عن [الموضوع].
موقفك: [حدّد].
البنية: افتتاحية جريئة، الحجّة الأولى، الحجّة الثانية، الحجّة الثالثة، رفض الاعتراضات الشائعة، خاتمة قوية.
```

### 8) مقال تحليل خبر

```
حلّل هذا الخبر: [ألصق].
البنية: ما حدث بجملة، السياق (لماذا مهمّ)، 3 تأثيرات محتملة، توقّعات، توصية للقارئ.
```

### 9) مقال بحث بيانات

```
حلّل هذه البيانات: [ألصق].
البنية: أهمّ 3 نتائج، جدول أو رسم بياني وصفي، 3 نتائج ثانوية، ما لا تُظهره البيانات (تحفّظات)، توصيات.
```

### 10) مقال SEO محسّن

```
اكتب مقالاً 1200 كلمة عن [الكلمة المفتاحية].
البنية: مقدّمة تحوي الكلمة في أوّل 100 كلمة، 5 عناوين H2 كل واحد يحوي كلمة مفتاحية مرتبطة، جدول، FAQ 5 أسئلة (Schema-ready)، خاتمة.
هدف SEO: ترتيب على صفحة Google الأولى لهذه الكلمة.
```

## للإيميلات (10 برومتات)

### 11) إيميل تقديم عرض

```
اكتب إيميلاً 150 كلمة أُقدّم به عرضاً تجارياً لعميل محتمل.
اسمه: [X]، شركته: [Y]، الخدمة: [Z].
اللهجة: مهنية دافئة.
CTA: طلب موعد 15 دقيقة.
```

### 12) إيميل متابعة

```
اكتب إيميل متابعة لعميل لم يردّ على عرضنا السابق (أسبوع منذ الإرسال).
الهدف: تحفيز الرد بلا ضغط.
اقترح: تسهيل (تقليل السعر / تجربة مجانية).
```

### 13) إيميل تعريف بمنتج

```
اكتب إيميلاً 200 كلمة أُعرّف بمنتجنا الجديد [X].
الجمهور: قاعدة عملاء حاليّين.
البنية: تحيّة، مشكلة يعرفونها، حلّنا، ميزتان رئيسيتان، عرض تخفيض 20% للأسبوع.
```

### 14) إيميل شكر عميل

```
اكتب إيميل شكر لعميل [الاسم] بعد شرائه [المنتج/الخدمة].
اللهجة: صادقة دافئة، بلا مبالغة.
اذكر خطوة تالية عملية.
```

### 15) إيميل اعتذار

```
اكتب إيميل اعتذار للعميل [الاسم] بعد [المشكلة: صف].
البنية: اعتراف واضح بالخطأ، شرح مختصر بلا أعذار، الحلّ الآن، ما نفعله لمنع التكرار.
لهجة صادقة مسؤولة.
```

### 16) إيميل استقبال (Welcome)

```
اكتب إيميل ترحيب لعميل جديد اشترك في [المنتج].
البنية: ترحيب، ما التالي (3 خطوات)، من نحن، كيف يتواصل معنا.
```

### 17) إيميل نيوزلتر أسبوعي

```
اكتب نيوزلتر أسبوعياً لقائمة بريدية عن [المجال].
البنية: افتتاحية شخصية 100 كلمة، 3 أخبار مهمّة (كل واحد جملة + رابط)، أداة/موقع أنصح به، سؤال للأسبوع.
```

### 18) إيميل دعوة لحدث

```
اكتب إيميل دعوة لحدث [الاسم]، [التاريخ]، [المكان].
الجمهور: [حدّد].
البنية: هوك، ما الحدث، لماذا يستحقّ، تفاصيل، تسجيل.
```

### 19) إيميل استفسار احترافي

```
اكتب إيميلاً استفساراً احترافياً لشركة [X] عن خدمتهم [Y].
البنية: تعريف مختصر بي، ما أحتاج، أسئلة محدّدة (3-5)، شكر.
لهجة مهنية موجزة.
```

### 20) إيميل رفض مؤدّب

```
اكتب إيميلاً أرفض به [العرض / الطلب / التعاون].
البنية: شكر، سبب مختصر (بلا اعتذار مفرط)، تمنّي التوفيق، إبقاء الباب مفتوحاً لمستقبل مختلف.
```

## للسوشيال ميديا (10 برومتات)

### 21) منشور LinkedIn

```
اكتب منشور LinkedIn 200 كلمة عن [الموضوع].
افتتاحية تصدم في أوّل جملة.
قصّة شخصية بتفصيل محدّد.
درس واحد.
سؤال يدعو للتعليق.
لا هاشتاق أكثر من 3، لا إيموجي أكثر من 2.
```

### 22) تغريدة X

```
اكتب تغريدة قصيرة عن [الموضوع].
280 حرفاً كأقصى.
مثيرة للتفاعل (رأي جريء، إحصاء صادم، سؤال).
```

### 23) ثريد X

```
اكتب ثريد X من 7 تغريدات عن [الموضوع].
التغريدة الأولى: هوك يجذب.
التغريدات 2-6: كل واحدة نقطة.
التغريدة السابعة: خلاصة + CTA.
```

### 24) منشور Instagram (Caption)

```
اكتب كابشن Instagram لصورة عن [الموضوع].
البنية: هوك في أوّل جملة، قصّة قصيرة (100-150 كلمة)، سؤال، هاشتاقات (10-15 مناسبة).
```

### 25) نصّ Reel

```
اكتب سكريبت Reel 30 ثانية عن [الموضوع].
البنية: هوك (3 ثوانٍ)، محتوى (25 ثانية، 3 نقاط)، CTA (2 ثانية).
لغة محكية بسيطة.
```

### 26) منشور Facebook

```
اكتب منشور Facebook لجمهور [صف].
البنية: هوك، محتوى قصير 100 كلمة، دعوة للتفاعل.
```

### 27) وصف يوتيوب

```
اكتب وصف فيديو يوتيوب عن [الموضوع].
البنية: أوّل سطرين يعرّفان + كلمة مفتاحية، شرح تفصيلي 200 كلمة، فصول زمنية (Timestamps)، روابط ذات صلة، هاشتاقات.
```

### 28) عنوان يوتيوب

```
اكتب 10 عناوين يوتيوب لفيديو عن [الموضوع].
كل عنوان تحت 60 حرفاً، يجذب النقر، بدون خداع.
```

### 29) بوست Threads

```
اكتب بوست Threads (Instagram) عن [الموضوع].
لهجة شخصية، جملتان-ثلاث، بدون هاشتاق.
```

### 30) TikTok Script

```
اكتب سكريبت TikTok 45 ثانية عن [الموضوع].
هوك أوّل 3 ثوانٍ، بناء توتّر، ذروة، خاتمة سريعة.
```

## للتقارير والوثائق (10 برومتات)

### 31) تقرير تنفيذي

```
اكتب تقريراً تنفيذياً 500 كلمة عن [الموضوع/المشروع].
البنية: ملخّص تنفيذي (100 كلمة)، السياق، النتائج (بأرقام)، التوصيات، الخطوات التالية.
لهجة مهنية، مباشر.
```

### 32) عرض تقديمي (Slides)

```
اكتب محتوى عرض تقديمي 10 شرائح عن [الموضوع].
كل شريحة: عنوان + 3-5 نقاط + ملاحظة للمتحدّث.
```

### 33) مقترح مشروع

```
اكتب مقترح مشروع للعميل [X].
المشروع: [صف].
البنية: نظرة عامّة، الأهداف، النطاق، المنهجية، الجدول الزمني، التكلفة، الفريق، شروط.
```

### 34) عقد خدمة مبسّط

```
اكتب مسوّدة عقد خدمة مبسّطة بين [الطرفين].
الخدمة: [صف].
البنوني: أطراف، مدّة، مقابل، حقوق كل طرف، إنهاء، حلّ نزاعات.
لغة بسيطة، لكن كاملة.
تذكير: هذه مسوّدة، مراجعة محامٍ لازمة قبل التوقيع.
```

### 35) محضر اجتماع

```
حوّل هذه الملاحظات إلى محضر اجتماع رسمي: [ألصق].
البنية: تاريخ، حاضرون، الأجندة، ما نوقش لكل بند، القرارات، المهامّ (من يفعل ماذا متى).
```

### 36) خطّة تسويقية

```
اكتب خطّة تسويقية للربع القادم لـ[الشركة/المنتج].
البنية: الأهداف، الجمهور، الرسالة، القنوات، الميزانية، KPIs، الجدول الزمني.
```

### 37) SWOT Analysis

```
اكتب تحليل SWOT لـ[الشركة/المشروع].
النقاط بأمثلة محدّدة، لا عموميات.
اختم بأهمّ فرصة يجب اقتناصها.
```

### 38) استبيان عملاء

```
اكتب استبيان 10 أسئلة لعملاء [الخدمة].
الهدف: [صف].
مزيج: أسئلة كمّية (تقييم 1-5)، ونوعية (شرح).
```

### 39) FAQ لموقع

```
اكتب FAQ لصفحة [الموضوع] في موقع [X].
10 أسئلة يطرحها العميل فعلاً.
كل جواب 2-4 جمل واضحة.
```

### 40) وصف منتج (E-commerce)

```
اكتب وصف منتج لـ[اسم المنتج] في متجر إلكتروني.
البنية: عنوان جذّاب، فوائد رئيسية (3 نقاط)، مواصفات (جدول)، من هو له، ضمان.
لا مبالغة، صادق.
```

## للإبداع (10 برومتات)

### 41) قصّة قصيرة

```
اكتب قصّة قصيرة 500 كلمة عن [الموضوع].
شخصية رئيسية: [صف].
البنية: تعريف بالشخصية، حدث محفّز، ذروة، حلّ.
أسلوب سردي غير متوقّع.
```

### 42) قصيدة

```
اكتب قصيدة عربية 12 بيتاً عن [الموضوع].
الأسلوب: [عمودي / تفعيلة / حرّ].
مشاعر: [حزن / فرح / تأمّل].
لا مبالغة عاطفية.
```

### 43) سيناريو حوار

```
اكتب حواراً بين [الشخصيتَين] عن [الموضوع].
كل شخصية بأسلوبها المميّز.
درامي، بلا سطحية.
```

### 44) خطاب

```
اكتب خطاب [تخرّج/زواج/تكريم/تقاعد].
المتحدّث: [صف].
المناسبة: [صف].
لهجة: [رسمية/دافئة/فكاهية].
مدّة: 3-5 دقائق قراءة.
```

### 45) عناوين مبدعة

```
اكتب 20 عنواناً مبدعاً لـ[كتاب/مقال/فيديو] عن [الموضوع].
10 عناوين مباشرة، 10 مثيرة للفضول.
```

### 46) شعار (Tagline)

```
اكتب 10 شعارات لعلامة [الاسم] في مجال [X].
كل شعار تحت 8 كلمات.
مختلفة في الأسلوب (وظيفي، عاطفي، جريء، محافظ).
```

### 47) نصّ راديو

```
اكتب نصّ إعلان راديو 30 ثانية لـ[المنتج/الخدمة].
هوك، وعد، CTA.
لغة محكية بسيطة.
```

### 48) كلمات أغنية

```
اكتب كلمات أغنية عربية عن [الموضوع].
اللهجة: [فصحى/سعودية/مصرية].
مقاطع: قرار (كورس)، مقطع 1، قرار، مقطع 2، قرار، ختام.
مشاعر واضحة.
```

### 49) نصّ خيالي

```
اكتب مشهداً خيالياً 300 كلمة عن [العالم/السيناريو].
حسّي، تفاصيل بصرية وصوتية.
```

### 50) رسالة عائلية

```
اكتب رسالة من [الأب/الأمّ/الابن] لـ[الطرف الآخر] عن [الموضوع].
لهجة عاطفية صادقة، بلا مبالغة.
مقاطع قصيرة، بلغة يومية.
```

## كيف تستخدم هذه المكتبة

1. **اختر البرومت** المناسب لمهمّتك
2. **استبدل النصّ** بين [الأقواس] بمعلوماتك
3. **الصق** في ChatGPT/Claude/Gemini
4. **راجع** المخرج
5. **عدّل** البرومت إذا لم يعجبك، احتفظ به إذا نجح

## نصائح للاستخدام

- **لا تقبل أوّل إجابة**: اطلب بدائل، اختصر، وسّع
- **أضف سياقك**: كل برومت يستفيد من سياقك الخاصّ (اسم، مدينة، تفصيل شخصي)
- **احفظ الناجحة**: بنك برومت شخصي = وقت موفَّر
- **اختبر بين النماذج**: Claude للأدب، ChatGPT للتنوّع، Gemini للسرعة
