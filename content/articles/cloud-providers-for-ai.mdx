  - q: "كم يكلّف Cloud AI؟"

  - q: "ما الفرق بين Cloud AI و OpenAI Direct؟"

**مزوّدو السحابة** يوفّرون البنية التحتية لأغلب تطبيقات AI العالمية. الاختيار بينهم يُشكّل مستقبل مشروعك. هذا الدليل شامل، مع تركيز على الخيارات السعودية.

## المشهد

### حصص السوق (2026)

- AWS: 33% (الأكبر)
- Azure: 24%
- Google Cloud: 11%
- Alibaba Cloud: 4%
- باقي: 28% (Oracle، IBM، مزوّدون محلّيون)

### الحجم

- الإنفاق العالمي على Cloud: 700+ مليار$ (2026)
- حصّة AI منه: 30%+ (يتزايد بسرعة)
- السعودية: 5+ مليار$ Cloud spending سنوياً

## AWS

### الخلفية

- **Amazon Web Services**
- **الأكبر** منذ 2006
- **الأشمل**، كل الخدمات

### AI Services

**Amazon Bedrock**:
- منصّة للنماذج المتعدّدة
- **Anthropic Claude** (استثمرت Amazon 4 مليار$)
- **Meta Llama**
- **Mistral**
- **AI21 Jurassic**
- **Stability Stable Diffusion**
- **Amazon Titan** (نماذج AWS الخاصّة)
- **Cohere**

**Amazon SageMaker**:
- منصّة ML شاملة
- تدريب، نشر، مراقبة
- **الأشهر** للـData Scientists

**Amazon Q**:
- **Amazon's AI Assistant**
- منافس ChatGPT للـEnterprise
- **Amazon Q Developer**، منافس Copilot للمطوّرين

**Amazon Rekognition** (رؤية):
- تحليل الصور والفيديو
- التعرّف على الوجوه (مثير للجدل)

**Amazon Polly**: توليد صوت
**Amazon Transcribe**: تفريغ صوت (بالعربية جيّد)
**Amazon Translate**: ترجمة

### السعودية

- **AWS Local Zones** في السعودية (منذ 2024)
- **Amazon مركز جدّة**
- **بيانات محلّية**

### الأسعار

- Free Tier: 12 شهر
- On-demand: أغلى، مرن
- Reserved Instances: أرخص 50-70% مع التزام سنوي
- Savings Plans: مرن

## Microsoft Azure

### الخلفية

- **Microsoft Azure**
- **الثاني عالمياً**
- **الشراكة مع OpenAI**، 13+ مليار$

### AI Services

**Azure OpenAI Service**:
- **نماذج OpenAI** (GPT-5, GPT-4o, o3, DALL-E 3, Whisper)
- **بنية Azure المؤسّسية**
- **Compliance، SLA، Regional**
- **الأشمل مؤسّسياً** لـOpenAI

**Azure AI Studio**:
- منصّة موحّدة لبناء تطبيقات
- **Prompt Flow** (للتصميم البصريّ)
- **Content Safety** (Guardrails)

**Azure AI Search** (سابقاً Cognitive Search):
- **RAG جاهز**
- Vector Search
- Semantic Search

**Azure Machine Learning**:
- ML شامل
- **MLOps** كامل

**Azure Cognitive Services**:
- Vision، Speech، Language، Decision
- **الأنضج مؤسّسياً**

**Copilot Studio**:
- بناء وكلاء بلا كود
- منافس Custom GPTs

### السعودية

- **Azure Saudi Arabia**، Data Center **افتُتح 2024**
- **بيانات محلّية**
- **Compliance مع PDPL**

### الأسعار

- Pay-as-you-go
- Reserved Instances
- **Enterprise agreements** (خصومات ضخمة)

### الأنسب لـ

- شركات تستخدم Microsoft (Office، Windows)
- تريد GPT مع بنية مؤسّسية
- **الاندماج مع M365**

## مقارنة الأسعار، استخدام حقيقي

**سيناريو**: تطبيق شات بوت يستقبل 100,000 استفسار/شهر بمتوسّط 500 توكن مدخل + 500 مخرج.

**GPT-5 mini على Azure**:
- 50M input tokens × $0.15/M = $7.50
- 50M output tokens × $0.60/M = $30
- Total: ~$40/شهر (بلا حساب Infrastructure)

**Claude Haiku على AWS Bedrock**:
- Input: 50M × $0.25/M = $12.50
- Output: 50M × $1.25/M = $62.50
- Total: ~$75/شهر

**Gemini Flash على Vertex AI**:
- Input: 50M × $0.10/M = $5
- Output: 50M × $0.40/M = $20
- Total: ~$25/شهر (**الأرخص**)

**النتيجة**: للاستخدام العالي، **الفرق كبير**. اختر بحكمة.

## نصيحة نهائية

**للـStartup السعودي**:
1. **ابدأ بـFree Tier** (كل مزوّد)
2. **جرّب Azure OpenAI** للـGPT، **AWS Bedrock** لـClaude، **Vertex AI** لـGemini
3. **قِس الأداء والتكلفة**
4. **اختر بناءً على البيانات**

**للمؤسّسة السعودية**:
- Data محلّية: Google Cloud Riyadh أو Oracle
- Microsoft heavy: Azure
- الحكومي: HUMAIN Cloud (قادم)

**للمطوّر الفرد**:
- **OpenAI Direct** أبسط للبدء
- **Cloud** لاحقاً عند التوسّع
