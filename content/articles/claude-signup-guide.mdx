Claude هو النموذج الأقلّ شهرة بين الثلاثة الكبار، لكن الأكثر تفضيلاً لدى المطوّرين والكتّاب المحترفين. Anthropic بُنيت عام 2021 من مؤسّسي OpenAI السابقين بهدف بناء "AI آمن قابل للتفسير". هذا الدليل يشرح التسجيل والاستخدام.

## قبل التسجيل

**تحتاج**:
- إيميل
- رقم جوّال (سعودي +966 مقبول)
- متصفّح حديث
- ~3 دقائق

**لا تحتاج**:
- VPN
- بطاقة بنكية (للمجاني)
- تسجيل مسبق في خدمة أخرى

## الخطوة 1: افتح Claude

**من الكمبيوتر**: [claude.ai](https://claude.ai)

**من الموبايل**:
- iPhone: App Store → "Claude by Anthropic" الرسمي
- Android: Google Play → "Claude by Anthropic" الرسمي

## الخطوة 2: اضغط "Sign up"

الشاشة الرئيسية بها زرَّان:
- **Log in**، لو عندك حساب
- **Sign up**، للحساب الجديد

## الخطوة 3: اختر طريقة التسجيل

**الأسرع**:
- **Continue with Google** (موصى به)
- **Continue with Apple**

**البديل**:
- **Email + Password**، أدخل إيميلك، ضع كلمة سرّ قوية، تحقّق عبر إيميلك

## الخطوة 4: تأكيد رقم الجوّال

بعد التسجيل بأيّ طريقة:

1. أدخل اسمك
2. أدخل رقم جوّال، **+966 5X XXX XXXX**
3. يصلك رمز عبر SMS
4. أدخل الرمز

**ملاحظات**:
- رقم واحد لحساب واحد
- الرقم السعودي يعمل مباشرة
- لا تستخدم Google Voice أو أرقام مؤقّتة

## الخطوة 5: أوّل محادثة

الواجهة أبسط من ChatGPT:
- **صندوق الرسائل**، أسفل الوسط
- **قائمة المحادثات**، الجانب الأيسر
- **Projects**، أعلى القائمة (بعد الترقية لـPro)
- **الإعدادات**، أعلى اليمين

**جرّب**:
```
مرحباً، عرّف نفسك واذكر ٥ مهامّ أنت أفضل فيها من ChatGPT.
```

Claude سيجيب بصراحة (وهذه ميزته، لا يبالغ).

## الخطوة 6: افهم النماذج

Claude له نماذج بمستويات:

| النموذج | متى تستخدمه |
|---|---|
| **Claude Haiku 4** | أسرع، للأسئلة القصيرة، معالجة ملفّات متكرّرة |
| **Claude Sonnet 4.7** | الأشمل، للاستخدام اليومي، الكود، الكتابة |
| **Claude Opus 4** | الأقوى، للمشاريع المعقّدة (متاح Pro/Max/Team) |

**Extended Thinking** (متاح على Sonnet وOpus): يفعّل "التفكير الطويل"، Claude يفكّر دقائق قبل الرد، مفيد للمسائل المعقّدة.

## الخطوة 7: الفرق بين Free وPro وTeam

### Claude Free

- Sonnet 4.7 بحدّ يومي (كافٍ للاستخدام العادي)
- تحليل ملفّات وصور
- Web search (محدود)
- بلا Projects

### Claude Pro ($20/شهر)

كل المجاني +
- Sonnet 4.7 بلا حدود عملية
- Opus 4 بحدّ محدود (للمهام الصعبة)
- **Projects**، مساحات عمل منظّمة
- **Extended Thinking** أطول
- **Google Workspace integration** (Gmail، Docs، Calendar)
- استخدام أعلى من الأدوات (MCP)

### Claude Team ($25/شهر/عضو، حدّ 5 أعضاء)

كل Pro +
- مساحة عمل مشتركة
- بيانات معزولة (لا تدريب)
- إدارة أعضاء
- ضمانات SOC 2

### Claude Max ($100 أو $200/شهر)

- استخدام Opus أعلى بكثير
- Priority access في أوقات الازدحام
- المحترفون المكثّفون

### Claude Enterprise

- مخصّصة للمؤسّسات الكبيرة
- عزل بيانات كامل
- SSO، Audit logs
- تسعير مخصّص

## الخطوة 8: Projects، الميزة السرّية

**ما هو Project**: مساحة عمل لمشروع طويل الأمد. تضع:
- **تعليمات المشروع** (مثل: "أنت مساعد قانوني لقضية X. الأسلوب رسمي، اللغة العربية.")
- **مستندات المشروع** (PDF، Word، صور، كلّها متاحة في كل محادثة)
- **محادثات متعدّدة** كلها تعرف السياق

**أمثلة استخدام**:
- محامٍ: Project لكل قضية، يحمّل مستندات القضية، كل محادثة تعرفها
- كاتب: Project لكل كتاب، يحمّل الفصول السابقة والملاحظات
- مطوّر: Project لكل مستودع، يحمّل كود المشروع
- باحث: Project لكل بحث، يحمّل الدراسات المرجعية

**الفرق مع ChatGPT**: Projects أقوى في التنظيم، وكل محادثة داخل Project تعرف كل المحمَّلات دون إعادة رفع.

## الخطوة 9: MCP، بروتوكول جديد

**Model Context Protocol**، بروتوكول أنشأته Anthropic 2024 يسمح لـClaude بالاتّصال بأدواتك:
- Google Drive → قراءة ملفّاتك
- GitHub → قراءة كودك
- Slack → قراءة محادثاتك
- قواعد بيانات → استعلامات آمنة
- APIs مخصّصة

**كيف تفعّل**: Settings → Integrations → أضف الخادم (Server) الذي تريد.

**التطبيقات المتاحة رسمياً**: Google Workspace، GitHub، Notion، Linear، Zapier، وأكثر.

## الخطوة 10: Computer Use (تجريبي)

Claude Sonnet 4.5+ يستطيع **رؤية شاشة جهازك والضغط على الأزرار**، أي يشغّل جهازك بدلاً منك.

**استخدامات**:
- تعبئة نماذج ويب طويلة
- بحث ومقارنة أسعار
- تصفّح تطبيقات

**الوصول**: عبر API فقط الآن (للمطوّرين). لا يزال تجريبياً.

## متى Claude يتفوّق على ChatGPT

### 1) الكتابة الطويلة الأدبية

كتاب، مقال 3000+ كلمة، رواية قصيرة. أسلوب Claude أنعم.

### 2) البرمجة المعقّدة

Cursor وWindsurf (أدوات المطوّرين المحترفين) اختارا Claude افتراضياً.

### 3) تعليمات دقيقة

"لا تفعل X"، Claude يلتزم أكثر. ChatGPT قد ينسى.

### 4) العمل مع مستندات طويلة

200K توكن سياق، مع دقّة عالية في التعامل مع الوسط.

### 5) الأمان والخصوصية

Anthropic تنشر أبحاثها الأمنية، سياساتها أوضح، Enterprise Grade من البداية.

## متى ChatGPT يتفوّق على Claude

- تريد توليد صور بلا انتقال لأداة أخرى
- تحتاج Sora للفيديو
- تحتاج Advanced Voice Mode للمحادثة الصوتية
- تريد Custom GPTs وGPT Store
- محتوى تعليمي عربي عن الأداة أكثر

## نصائح للاستخدام الأمثل

1. **جرّب Extended Thinking للمسائل الصعبة**، مفيد للتحليل والقرارات
2. **استخدم Projects لمشروع مهنيّ مستمرّ**، يوفّر ساعات
3. **فعّل MCP إذا كنت مطوّراً**، Google Drive وGitHub يفتحان قدرات جديدة
4. **لا تنسَ Artifacts**، مساحة عمل جانبية للكود والوثائق تعمل بالتوازي مع المحادثة
5. **جرّب Sonnet قبل Opus**، عادةً Sonnet كافٍ، وأسرع، وأرخص على API

## أمان حسابك

1. فعّل **Two-Factor Authentication**: Settings → Security
2. كلمة سرّ قوية
3. لا تُشارك حسابك
4. راقب النشاط في Settings → Audit
5. للمهنية الحسّاسة → Claude Team على الأقل
